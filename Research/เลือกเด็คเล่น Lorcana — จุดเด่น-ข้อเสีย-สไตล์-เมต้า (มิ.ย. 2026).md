## 0. เกมเล่นยังไง (มือใหม่อ่าน 1 นาที) ✅

- เป้าหมาย = **แข่งกันสะสม lore ใครถึง 20 ก่อนชนะทันที** (ไม่ใช่ตีคู่ต่อสู้ให้ตาย)
- ได้ lore หลักจาก **Quest** = exert (หมุนตะแคง) ตัวละคร เพื่อบวก lore ตามเลข ◇ บนการ์ด
- **จุดตึงของเกม:** ตัวที่ quest แล้วจะ exert ค้าง → คู่ต่อสู้ **Challenge** (เข้าปะทะ) ได้ → ต้องเลือกระหว่าง "quest กินแต้ม" vs "เปิดช่องให้โดนตี"
- **Evasive = keyword สำคัญสุดสำหรับมือใหม่** — ตัว Evasive ถูก challenge ได้เฉพาะตัวที่มี Evasive เหมือนกัน → ฉะนั้นเด็ค "Evasive" จึง quest ฟรีๆ คู่ต่อสู้แตะไม่ได้ = ครองเมต้า
- แพ้ทางที่สอง: ต้องจั่วตอนเด็คหมด = **deck-out** (control บางตัวใช้ปิดเกม)

> 6 สี ink: 🟠 Amber (ฮีล/ทน) · 🟣 Amethyst (จั่ว/เวท) · 🟢 Emerald (กวน/discard) · 🔴 Ruby (บุก Rush) · 🔵 Sapphire (ramp/value) · ⚪ Steel (ตั้งรับหนัก) — เด็คใช้ได้ **ไม่เกิน 2 สี**, ขั้นต่ำ 60 ใบ

## 3. เด็คสาย Evasive (ครองเมต้า — quest ฟรีคู่ต่อสู้แตะไม่ได้)

### 🥇 1. Amethyst/Sapphire Evasive — **S** · ⭐ เด็คอันดับ 1 (~19%)
- **สไตล์:** Evasive tempo — ramp ด้วย Sapphire → ลงตัว Evasive ที่คู่ต่อสู้ challenge ไม่ได้ → quest ไป 20 ขณะ Amethyst จั่วเลี้ยงมือ + มี board wipe กวาด blocker
- **จุดเด่น:** คู่ต่อสู้มัก **interact ไม่ได้เลย** · เครื่องจั่วแข็ง การ์ดไม่หมด · มีทั้งบุก (quest) + รับ (board wipe/removal) ยืดหยุ่นมาก · ผลแข่งจริงดี
- **ข้อเสีย:** แพ้ทาง **anti-evasive** (Alert / Violet Parr, Syndrome ที่ challenge evasive ได้) · combo piece หลายใบเป็น 1-of → ต้อง sequencing เก่ง · เจอ aggro เร็วสุดตอนจั่วช้าอาจโดนแซง
- **ความยากมือใหม่:** 🟠 กลาง–ยาก
- **ต้นทุน:** กลาง–แพง (อยากได้ chase rare)
- ⚠️ **rotation เสี่ยงสูง:** board clear **Monstro (Set 5)** หมุนออก → ต้องหา finisher ใหม่ post-ก.ค. (เครื่องจั่วรอด)

### 4. Amber/Amethyst Evasive — **A** (~13%)
- **สไตล์:** Evasive + card advantage — quest ด้วยตัว evasive ขณะ bounce/recur ตัวกลับมา กดดันให้คู่ต่อสู้เปลืองทรัพยากร แล้วลงคอมโบ value
- **จุดเด่น:** **ทน** (recursion/bounce ฝ่า removal ได้) · card advantage + คอมโบ upside สูง · quest evasive upside เท่าเด็คอันดับ 1
- **ข้อเสีย:** คอมโบพึ่ง 1-of → ไม่นิ่ง · ช้ากว่า aggro โดนกดตอนตั้งตัว · แพ้ทาง anti-evasive เหมือนกัน
- **ความยากมือใหม่:** 🟠 กลาง–ยาก (คอมโบ/recursion ต้องฝึก)
- **ต้นทุน:** กลาง
- 🟡 **rotation:** color identity ยาวข้ามหลายชุด → กลยุทธ์น่ารอด แต่ 1-of บางใบอาจหมุนออก

## 4. เด็คสาย Aggro / Control

### 🥈 2. Amber/Emerald Aggro — **S** · ⭐ คู่สียอดนิยมสุด (~17%)
- **สไตล์:** Aggro แท้ — ตัวถูก 1–2 cost lore สูง → ปั๊ม **4–6 lore/เทิร์นตั้งแต่ ~เทิร์น 3** → ปิดเกม **เทิร์น 5–6 ก่อนเทิร์น 7** ที่ control ติดเครื่อง
- **จุดเด่น:** **clock เร็วสุด** ลงโทษเด็คโลภ/ช้า · board ตัวละครล้วน ทุกใบคือภัย · **ถูกสุด + lines ง่าย** · มีตัวตอบ control (Ursula counter song)
- **ข้อเสีย:** เกมยืด (เกินเทิร์น 6–7) เจอ board wipe พับ · เจอเด็ค removal เยอะ (Ruby/Steel) เหนื่อย · ปรับกลางเกมยาก จั่วท้ายเกมแป้ก
- **ความยากมือใหม่:** 🟢 **ง่าย–กลาง** (เล่นตัวถูก quest ทุกเทิร์น = แผนเป็นมิตรมือใหม่สุด)
- **ต้นทุน:** 💰 **ถูก** (Tier-1 ที่ถูกสุด chase card น้อย)
- ✅ **rotation ดี:** aggro รีเฟรชง่าย ทน rotation สุด — น่ารอดแข็ง

### 🥉 3. Emerald/Sapphire Control — **A** (~13%)
- **สไตล์:** Control — Sapphire ramp เล่นนำเคิร์ฟ → Emerald กวน/discard + board wipe → พอเสถียรลงภัยตัวใหญ่ quest ปิด 20 ตอนปลายเกม
- **จุดเด่น:** **counter aggro/go-wide** ด้วย mass wipe · ramp ลงการ์ดแรงได้เร็ว · tutor/จั่ว หาคำตอบนิ่ง
- **ข้อเสีย:** **อ่อนช่วงต้นเกม** ก่อนตั้งตัว · พึ่งประกอบคอมโบ (ชิ้น wipe) · เคิร์ฟมีช่องโหว่ ⚠️ · โดน evasive ที่ข้าม board แซง tempo
- **ความยากมือใหม่:** 🔴 **ยาก** (decision เยอะสุด — ramp/removal/wipe sequencing) **ไม่แนะนำเป็นเด็คแรก**
- **ต้นทุน:** กลาง
- ⚠️ **rotation โดนหนักสุด:** ramp core **Tipo (Set 5)** + **Sail the Azurite Sea (Set 6)** หมุนออกทั้งคู่ → **เสียเครื่องยนต์ ก.ค.** ต้อง rebuild หนัก

### 5. Amber/Ruby Toys (Pixar/Toy Story) — **B** (~5%)
- **สไตล์:** Tribal midrange/tempo — สร้างรอบ **Toy** glimmer จาก Set 12 (synergy เผ่า + Ruby ปั่น lore)
- **จุดเด่น:** engine เผ่าใหม่ลึก · **สร้างจากชุดปัจจุบันล้วน → กัน rotation ดีสุด** · สนุก ธีมชัด มีที่ให้ brew
- **ข้อเสีย:** metashare ต่ำสุด (ยังไม่ refined) · tribal สะดุดถ้าจั่ว engine ไม่มา · data matchup น้อย
- **ความยากมือใหม่:** 🟡 กลาง (ธีมชัด แต่ guide/list ยังน้อย)
- **ต้นทุน:** ถูก–กลาง (ข้าม Iconic Buzz ที่ราคา $1,000+ ได้ — เป็นแค่ลายสวย ไม่จำเป็นต่อการเล่น)
- ✅ **rotation ดีสุด:** Set 12 ล้วน → รอด ก.ค. เต็มๆ + น่าจะโตขึ้น

## 6. 🎯 แนะนำมือใหม่ (เลือกตามสไตล์)

> [!check] เริ่มจาก 3 ตัวนี้ (ง่าย + ถูก + แข่งได้ + ทน rotation)
> 1. **Amber/Emerald Aggro** — 🥇 *เลือกแรกดีสุด* แผนง่ายสุด (ตัวถูก quest ทุกเทิร์น race ไป 20) · งบถูก · Tier S · **รอด rotation ก.ค.** → เรียนหัวใจเกม (quest vs challenge) ได้ไว
> 2. **Amber/Steel Aggro (budget)** — 🥈 ถูกที่สุด (~฿2,500–4,000) ขึ้นชื่อว่าเด็คทัวร์แรกที่เป็นมิตรสุด "ลงตัวถูก quest ชนะเทิร์น 7–8" (⚠️ เป็น staple งบประหยัด มากกว่า Tier-1 Core)
> 3. **Amber/Ruby Toys** — 🥉 *เด็คที่ "โตไปกับเกม"* กลางๆ แต่ **กัน rotation 100%** (Set 12 ล้วน) ธีมสนุก เริ่มถูกแล้วค่อยอัป → เหมาะถ้าอยากลงทุนของที่อยู่ยาวข้าม ก.ค.

> [!danger] เด็คที่มือใหม่ควร "เลี่ยงก่อน"
> **Emerald/Sapphire Control** — ยากสุด **และ** เสียเครื่องยนต์ ก.ค. (โดน 2 เด้ง) · เด็ค **Evasive** ทั้งคู่ — คอมโบ sequencing + A/S แพง + เสี่ยง rotation

**เลือกตามนิสัย:**
- ชอบ **บุกไว จบเร็ว เกมง่าย** → Amber/Emerald Aggro (หรือ Amber/Steel budget)
- ชอบ **เล่น tempo คู่ต่อสู้แตะไม่ได้** → Amethyst/Sapphire Evasive (โตแล้วค่อยเล่น)
- ชอบ **คุมเกมยาว board wipe** → Emerald/Sapphire Control (ยาก)
- ชอบ **ธีม/เผ่า สนุก ปั้นเอง** → Amber/Ruby Toys

> [!tip] เรื่องเงิน (มือใหม่จำข้อนี้พอ)
> เด็ค Tier-1 ราว **฿3,500–8,000** ขึ้นกับ chase · **ไม่จำเป็นต้องมี Iconic/Enchanted เลย** — เวอร์ชันธรรมดาแข่งได้เหมือนกัน (Iconic/Enchanted = แค่ลายสวย) · สลับเป็น regular foil ประหยัด 30–40%
