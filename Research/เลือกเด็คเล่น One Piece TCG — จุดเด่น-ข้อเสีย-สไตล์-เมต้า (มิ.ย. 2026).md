## 0. เกมเล่นยังไง (มือใหม่อ่าน 1 นาที)

- ทุกเด็ค = **Leader 1 ใบ** (เปิดหน้าตั้งแต่ต้น เป็นตัวกำหนดสี + ความสามารถ + life) + **เด็ค 50 ใบ**
- **DON!! = ทรัพยากร** — เพิ่มทีละ 1/เทิร์น (สูงสุด 10) ใช้จ่ายค่าร่ายตัวละคร/แปะเพิ่มพลังตอนตี
- **Life = การ์ดคว่ำ** — โดนตีทีละใบ พอ life หมดแล้วโดนตีอีก = **แพ้** (อีกทางคือจั่วจนเด็คหมด)
- เกมเป็น **race ตีเข้า life คู่ต่อสู้** ผสมการตั้งรับ (counter / blocker) → จุดต่างของแต่ละเด็คอยู่ที่ **ตีเร็ว (aggro) vs เล่นยาวกินแต้ม (control)**

> สี 6 สี: 🔴 Red (aggro) · 🟢 Green (rest/tempo) · 🔵 Blue (bounce/control) · 🟣 Purple (DON ramp) · ⚫ Black (cost-down/ลบ) · 🟡 Yellow (life/trigger) — เด็คเดียวมักใช้ 1–2 สี

## 1. Format & Banlist ปัจจุบัน ✅

- **ชุดล่าสุด = OP-16 "The Time of Battle"** วาง **12 มิ.ย. 2026** (JP/EN พร้อมกัน) → เมต้ายัง **ใหม่มาก (~2 สัปดาห์)** ยังไม่นิ่ง ✅
- **ไม่มี rotation** — ทุกชุดเก่ายังเล่นได้หมด (Standard โตขึ้นเรื่อยๆ ต่างจาก Lorcana/MTG)
- **Banlist (มีผล 1 เม.ย. 2026):** ✅
  - 🚫 **แบน:** Charlotte Pudding (OP06-047) — ใบเดียวที่แบนเต็ม
  - 🔗 **ห้ามคู่:** Borsalino (EB04-058) + "I Re-Quasar Helllp!!" (OP07-115) อยู่เด็คเดียวกันไม่ได้
  - ♻️ **ปลดแบน 6 ใบ:** Jinbe, Kingdom Come, Ice Age, Great Eruption, Moby Dick, Enies Lobby

> [!warning] ⚠️ ข้อมูลเมต้านี้ "เด็ก" มาก
> OP-16 เพิ่งวาง → ตัวเลข win-rate/metashare เป็นค่า**ประมาณ**จาก aggregator (blend หลายภูมิภาค) **เด็คใหม่ของ OP-16 (Luffy/Yamato/Teach) อันดับยังขยับได้** ส่วนเด็คเก่าที่พิสูจน์แล้ว (Nami/Enel) น่าเชื่อถือสุด — เช็กทัวร์ล่าสุดก่อนทุ่มซื้อ

## 3. เด็คสาย Control / Combo (ยาก แต่แข็งสุด)

### 🥇 Nami (น้ำเงิน/เหลือง) — **S** · ⭐ แข็งสุดในเมต้า
- **สไตล์:** Control / value engine — กดดัน life คู่ต่อสู้เพื่อ "ปั่นจั่วการ์ด" แล้วเล่นยาวกินทรัพยากรเหนือกว่า
- **จุดเด่น:** WR สูงสุดของ format · เครื่องจั่วเลี้ยงตัวเอง การ์ดแทบไม่หมดมือ · พึ่งดวง (coin-flip) ต่ำสุด · แก้ Boa/Imu ได้ดี
- **ข้อเสีย:** เทิร์น 1–3 อ่อน ก่อน Robin/Hiyori ตั้งตัว → โดน aggro รุมได้ · Robin เป็นจุดตาย ถ้าโดนเก็บ engine สะดุด · ตั้งรับแค่ 7000 เจอตี 9000+ เหนื่อย
- **ความยากมือใหม่:** 🔴 **ยาก** (sequencing + จัดมือ + คำนวณตั้งรับเยอะ)
- **ต้นทุน:** กลาง–แพง

### 🥈 Enel (ม่วง) — **S**
- **สไตล์:** Ramp/tempo-combo — cap DON ที่ 6 แล้ว ramp ออกตัวถูกบุกไว ปิดเกมด้วย Enel 6-cost (10000) ที่ลบยาก
- **จุดเด่น:** WR ~56.5% ชนะทัวร์อันดับ 2 · ramp ให้ตัวถูกข่มได้เร็ว · มี event 0-cost + blocker ตั้งรับแน่น
- **ข้อเสีย:** พึ่งดวงมากกว่า Nami (ชอบเล่นก่อน) · resource loop ซับซ้อน misplay ง่าย · ต้องปิดด้วย finisher Enel ให้ได้
- **ความยากมือใหม่:** 🔴 **ยาก**
- **ต้นทุน:** แพง (alt-art Enel ราคาสูง)

### Teach / หนวดดำ (ดำ/เหลือง, OP16-080) — **S ใหม่**
- **สไตล์:** Defensive grind + redirect — ทิ้งการ์ด trait [Trigger] เพื่อ **เปลี่ยนเป้าการโจมตี** มาที่หนวดดำ ดูดดาเมจ แล้วกินแต้ม
- **จุดเด่น:** ตัวเดียวที่กินทั้ง Nami และ Enel = pick anti-meta ดีสุด · skill ceiling สูงสุด ยิ่งเก่งยิ่งแรง · disruption ป่วน combat คู่ต่อสู้
- **ข้อเสีย:** **พึ่งดวงมากสุดใน format** (อยากเล่นทีหลัง ~+16.7 pt) · ต้องมี Trigger ในมือพอ · ปั่นพลาดเจ็บหนัก
- **ความยากมือใหม่:** 🔴 **ยากสุด**
- **ต้นทุน:** แพง (SEC leader ใหม่ ราคาพุ่ง)

### Rosinante (ม่วง — Navy) — **A** (OP-16 บัฟ)
- **สไตล์:** Navy ramp-control — ใช้ของใหม่ OP-16 (Sakazuki OP16-065, Koby search) ramp + ลบภัย + กินยาว
- **จุดเด่น:** ได้ของหนุนเยอะใน OP-16 (typing Navy สำคัญขึ้น) · Sakazuki + Gum-Gum Lightning ลบได้กว้าง · core หาง่าย (Koby ค้น)
- **ข้อเสีย:** ช้า โดน aggro แซงก่อน control ติด · build ยังใหม่ ปรับอยู่ · พึ่งการลบ → เจอ recursion/go-wide (Imu/Yamato) เหนื่อย
- **ความยากมือใหม่:** 🔴 ยาก
- **ต้นทุน:** กลาง–แพง

## 4. เด็คสาย Aggro / Tempo (เข้าใจง่ายกว่า บุกเป็นหลัก)

### Luffy OP16-022 (เขียว/น้ำเงิน) — **S/A ใหม่** · ⭐ มือใหม่เล่นได้
- **สไตล์:** Tempo/board — leader 4 life, untap DON ได้ถ้าบนสนามมีแต่ Impel Down; เล่น 2 กองตัวละคร (Impel Down + หมวกฟาง) รุมตัวถูก
- **จุดเด่น:** JP week-1 S · ranked ~22% (เล่นเยอะสุดในของใหม่) · **2 ฝ่ายซ้ำซ้อน** โดนป่วนฝ่ายเดียวไม่ล่ม · ยืดหยุ่น ไม่พึ่ง finisher ใบเดียว
- **ข้อเสีย:** ผลทัวร์ยังตามหลังเด็คเก่า · ต้องมี board ถึง untap DON ได้ → เจอ sweeper เจ็บ · เพดานการ์ดเดี่ยวต่ำกว่าสาย combo
- **ความยากมือใหม่:** 🟢 **ง่าย–กลาง** (ระบุว่า beginner-friendly)
- **ต้นทุน:** ถูก–กลาง (key card rarity ต่ำ ต่อยอดจาก starter ได้)

### Yamato (ดำล้วน, OP16-079) — **S/A ใหม่** · ⭐ aggro top-tier ที่นิ่ง
- **สไตล์:** Recursion-aggro — ให้ Rush กับตัว Wano ที่เล่นจาก trash → จู่โจมเซอร์ไพรส์ + สร้าง board ใหม่จากหลุมศพซ้ำๆ
- **จุดเด่น:** JP week-1 S · **ทน board wipe** (trash เติม board คืน) · **นิ่งกว่า Teach มาก** (พึ่งดวงต่ำ เล่นก่อน/หลังเกมหน้าตาเหมือนกัน) → เหมาะตอนยังหัดเล่น
- **ข้อเสีย:** WR ดิบต่ำกว่า Teach · เจอ trash-hate/banish โดนตรงจุด · บุกแล้วถ้ายืดเจอ control (Nami) อาจหมดแรง
- **ความยากมือใหม่:** 🟡 **กลาง** (loop บุกตรงไปตรงมา แต่ sequencing trash ต้องฝึก)
- **ต้นทุน:** กลาง (mono-color จัดการ DON ง่าย)

### Ace (แดง/น้ำเงิน) — **A**
- **สไตล์:** Aggro-midrange — leader 6000, ตั้งรับลบพลัง −2000, มี DON แปะแล้วจั่วตอนโดนดาเมจ/เก็บตัว 6000+
- **จุดเด่น:** aggro มีจั่วในตัว เล่นยาวได้ · ทริค −2000 ตั้งรับบลัฟการตี · ผลทัวร์สม่ำเสมอ
- **ข้อเสีย:** ตันเมื่อเจอ control แท้ (Nami) ถ้าปิดไม่ลง · กินทรัพยากร (ทิ้งการ์ดตอนรับ) · race พึ่งดวง
- **ความยากมือใหม่:** 🟡 กลาง
- **ต้นทุน:** กลาง–แพง (Ace SEC alt-art แพง)

### Lucy (แดง/น้ำเงิน) — **A**
- **สไตล์:** Event-combo — ทิ้ง Event เพิ่ม +1000/ใบ (บุกหรือรับก็ได้) + จั่วเมื่อเล่น Event 3+
- **จุดเด่น:** Event ใช้ได้ทั้งบุก+รับ (หายากสำหรับ event deck) · มีจั่วเลี้ยง Event · power spike ทำให้คู่ต่อสู้คำนวณยาก
- **ข้อเสีย:** พึ่งจั่ว/ถือ Event ให้ถูกใบ · เจอ engine จั่วของ Nami แพ้ยาว · พึ่งมือ โดนป่วนมือเจ็บ
- **ความยากมือใหม่:** 🟡 กลาง–ยาก (นับ Event + จังหวะทิ้ง)
- **ต้นทุน:** กลาง

## 6. 🎯 แนะนำมือใหม่ (เลือกตามสไตล์ที่ชอบ)

> [!check] เริ่มจาก 3 ตัวนี้ (ง่าย + ไม่แพงเกิน + ยังแข่งได้)
> 1. **Luffy OP16-022 (เขียว/น้ำเงิน)** — 🥇 *เลือกแรกดีสุด* beginner-friendly, ทน, top-tier, key card ถูก → เรียนพื้นฐานบนเด็คที่ชนะทัวร์ได้จริง
> 2. **Buggy (น้ำเงิน, swarm)** — 💰 *งบน้อยสุด* บุก go-wide เกมตัวเลขล้วน เหมาะหัดคำนวณ combat ต่อยอด single ~$40–60 ก็แข่งได้
> 3. **Yamato (ดำล้วน)** — 🔥 *อยาก top-tier เลย* S-tier + พึ่งดวงต่ำ (เล่นก่อน/หลังเหมือนกัน เหมาะตอนยังมือใหม่) + แผน "ตีจาก trash" เข้าใจง่าย

> [!danger] เด็คที่มือใหม่ควร "เลี่ยงก่อน"
> **Nami · Enel · Teach · Rosinante** — แข็งสุดก็จริง แต่เป็น control/combo skill ceiling สูง + แพง → เก่งพื้นฐานก่อนค่อยขยับมา

**เลือกตามนิสัย:**
- ชอบ **บุกไว จบเร็ว** → Buggy / Shanks / Yamato / Ace
- ชอบ **วางแผนยาว เอาชนะด้วยหัว** → (โตแล้วค่อย) Nami / Enel
- ชอบ **ป่วน/พลิกเกม** → Teach / Imu
- ชอบ **ยืดหยุ่นสมดุล** → Luffy OP16-022 (ตัวเริ่มที่ดีสุด)

## 7. ⏳ ชุดหน้า OP-17 — เมต้าจะขยับ (ก.ย. 2026) ✅

- **OP-17 "The World's Strongest Warriors"** EN วาง ~**22–28 ส.ค. 2026** (ครบรอบ 4 ปี, 126+1 ใบ, TR ใหม่)
- ธีม: เอา **leader คลาสสิกกลับมาเป็น leader ใหม่** + ตัว Impel Down/Marineford (Whitebeard, Luffy variants) → ตั้งใจ **เขย่าเมต้า**
- **นัยกับมือใหม่:** tier list OP-16 จะเปลี่ยนราว **ก.ย. 2026** → ลงทุนแรกควรเป็นเด็ค**ฝึกพื้นฐานราคาถูก (Luffy/Buggy)** ปลอดภัยกว่าทุ่มเด็ค top-tier แพงที่อาจตกชั้น
