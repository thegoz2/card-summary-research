# แผนปฏิบัติ OP TCG ตามงบประมาณ (Action Plan)

> [!info] โน้ตปิดจ๊อบ (2026-06-16) — สังเคราะห์จากงานวิจัย 10 รอบใน vault นี้
> นี่คือ "แผนลงมือทำจริง" ไม่ใช่ข้อมูลดิบ — ทุกข้อลิงก์กลับไปโน้ตที่มีรายละเอียด/แหล่งอ้างอิง

← ศูนย์กลาง: [[One Piece TCG - ทำกำไร (ภาพรวม)]]

> [!danger] กฎเหล็ก 3 ข้อก่อนเริ่ม (อ่านก่อนใช้เงิน)
> 1. **อย่าเปิดบูธจุ่มเอง** จนกว่าจะปรึกษาทนาย — เข้าข่าย พ.ร.บ.การพนัน 2478 โทษจำคุก ([[กลยุทธ์ จุ่ม (Lucky Dip) - OP TCG]])
> 2. **การ์ดโดยรวมไม่ใช่การลงทุนที่ดี** (พอร์ต Pokémon −4.72%/ปี ช่วง 2021-23) — ใช้เงินเย็น **ห้ามก่อหนี้** ([[กลุ่มลูกค้า และ พฤติกรรมผู้ซื้อ OP TCG]])
> 3. **ตลาดร้อนจัด = เสี่ยงฟองสบู่** (Luffy +215% YoY) — จับจังหวะ + เลือกของ สำคัญกว่าตามกระแส ([[ไทม์ไลน์ตลาด OP TCG 2022-2026]])

---

## 🧱 ขั้นพื้นฐาน (ทำก่อนทุกงบ — ฟรี/เกือบฟรี)

- [ ] **เรียนรู้ระบบ rarity + ราคา:** C/UC/R/SR/SEC, Leader, alt-art, **Manga Rare (หายาก/แพงสุด)** → [[ทำไมการ์ด OP TCG ถึงแพง (ปัจจัยราคา)]]
- [ ] **ติดตามราคาจริง:** TCGplayer, eBay (EN), SASOM (ไทย) — เทียบราคาก่อนซื้อทุกครั้ง
- [ ] **เข้าใจ JP vs EN:** ไทยขาย JP เป็นหลัก, JP = 144 ใบ/กล่อง, EN = 288 ใบ/กล่อง → [[ค่าส่ง อากรไทย และ สเปกกล่อง JP-EN - OP TCG]]
- [ ] **รู้จักร้าน/ช่องทางไทย:** MBK (Pro Card/Quest), Mega Plaza สะพานเหล็ก (CJR), SASOM, Shopee/Lazada → [[ตลาด OP TCG ในไทย (เจาะลึก)]]
- [ ] **ตั้งงบที่ "เสียได้"** + เปิดบัญชีแยกสำหรับงานนี้

---

## 💵 งบ < 20,000 บาท — โหมดเรียนรู้ (Learning Phase)

> 🎯 เป้าหมาย: **เรียนรู้ตลาด ไม่ใช่ทำกำไรก้อนใหญ่** — เงินก้อนนี้คือ "ค่าเรียน"

**ทำ:**
- [ ] ซื้อ **booster box เดี่ยว 1–2 กล่อง** ของชุดที่ chase แข็ง เก็บแบบ sealed (ดูชุดที่ chase ดีใน [[กลยุทธ์ ซื้อ Carton-Sealed - OP TCG]])
- [ ] เปิดบางส่วนเพื่อเรียนรู้การดูสภาพ + ลองขาย single บน SASOM/FB
- [ ] **ส่งเกรดทดลอง 1–2 ใบ** ผ่าน [[ตัวแทนส่งเกรดในไทย และ ค่าส่งไป-กลับ - OP TCG|CardKub]] (Regular 3,800 บาท/ใบ) เพื่อเรียนกระบวนการ
- [ ] เลือกใบที่จะส่งเกรดด้วย **กฎ 3–4 เท่า** (มูลค่า PSA 10 ที่คาด ≥ 3-4× ค่าเกรดรวม) → [[กลยุทธ์ ส่งเกรด PSA - OP TCG]]

**อย่าทำ:**
- ❌ ซื้อ carton เต็มลัง / เปิดบูธจุ่ม / ทุ่มชุดเดียว / ไล่ราคาการ์ดที่กำลังไวรัล

**ตัวชี้วัดความสำเร็จ:** ขาย single ออกได้จริง + เข้าใจว่าราคาขยับยังไง (ไม่ใช่กำไรเป็นเงิน)

---

## 💰 งบ 20,000–100,000 บาท — เริ่มจริงจัง

> 🎯 เป้าหมาย: **สร้างพอร์ต sealed + เริ่มหมุนเงินจาก single/graded**

**ทำ:**
- [ ] **แกนหลัก = Sealed:** ซื้อ **carton/case** ของชุดต้น ๆ หรือชุด chase แข็ง เก็บ sealed รอ appreciation
  - กระจาย **2–3 ชุด** ไม่ทุ่มชุดเดียว (ความเสี่ยง: ไม่ใช่ทุกชุดเป็น OP05)
- [ ] **เปิดบางส่วนขายปลีก:** เปิด box ขาย single ใบดัง + ส่งเกรดใบที่คุ้ม
- [ ] **ส่งเกรดเป็นกลุ่ม (group submission)** ผ่าน CardKub เพื่อแชร์ค่าประกัน/ค่าส่ง → ต้นทุนต่อใบลดลง
- [ ] **คำนวณต้นทุนนำเข้าให้ครบ** ถ้าซื้อจากต่างประเทศ: ของ + ค่าส่ง DHL (TH→HK 2,334-3,188 บาท) + ประกัน 2% + **อากร + VAT 7% ขากลับ** (de minimis ยกเลิกแล้ว) → [[ค่าเกรด PSA-CGC และ ภาษีนำเข้า Carton - OP TCG]]

**กลุ่มลูกค้าที่ขาย:** ผู้ใหญ่ 25–40 มีกำลังซื้อ (ชอบ graded/sealed/alt-art) → ทำกำไรต่อหน่วยสูง → [[กลุ่มลูกค้า และ พฤติกรรมผู้ซื้อ OP TCG]]

**อย่าทำ:**
- ❌ ดองเงินทั้งหมดในชุดเดียว / ซื้อตอนดัชนีพีค / เปิดบูธจุ่มไม่มีใบอนุญาต

---

## 🏦 งบ > 100,000 บาท — พอร์ตหลายกลยุทธ์

> 🎯 เป้าหมาย: **กระจายความเสี่ยง + ใช้ข้อได้เปรียบด้านสเกล**

**ทำ:**
- [ ] **พอร์ต sealed หลายชุด** (กระจายชุด/ภาษา) + **คลังการ์ด graded ใบแพง**
- [ ] **ส่งเกรดเป็นล็อต** ลดต้นทุนต่อใบ — พิจารณาส่งผ่าน **PSA/CGC ฮ่องกงเอง** (ถูกกว่าตัวแทน, เลี่ยงศุลกากร US ขาไป) → [[ตัวแทนส่งเกรดในไทย และ ค่าส่งไป-กลับ - OP TCG]]
- [ ] **เลือก service เกรดตามใบ:** ใบแพงเน้นขายต่อ → PSA (สภาพคล่องสูงสุด) | ใบเยอะไม่รีบ → CGC (flat TCG tier $20/ใบ ไม่จำกัดมูลค่า)
- [ ] **ติดตาม catalyst:** ข่าว reprint ของ Bandai (กดราคา), banlist (กระทบการ์ดเล่น), ค่าเงินเยน → [[อิทธิพลภายนอกต่อราคาการ์ด OP TCG]]
- [ ] **ถ้าสนใจ "จุ่ม" จริงจัง** → ปรึกษาทนายเรื่อง **ใบอนุญาต ม.8** ก่อน ทำให้ถูกกฎหมาย → [[กลยุทธ์ จุ่ม (Lucky Dip) - OP TCG]]

**อย่าทำ:**
- ❌ เปิดบูธจุ่ม/ไลฟ์สุ่มโดยไม่เช็กกฎหมาย (เทรนด์ RICO/ลอตเตอรีกำลังถูกจับตา) / ทุ่มหมดหน้าตักตอนตลาดร้อนสุด

---

## 🧭 Decision Tree เร็ว ๆ

```
อยากทำกำไร OP TCG?
├─ อยากเปิดบูธจุ่ม? ──► ⛔ หยุด! ปรึกษาทนาย ม.8 ก่อน (เสี่ยงสุด)
├─ งบ < 20k? ─────────► booster box เดี่ยว + เกรดทดลอง 1-2 ใบ (เรียนรู้)
├─ งบ 20k-100k? ──────► carton 2-3 ชุด (sealed) + group grading ใบคุ้ม
└─ งบ > 100k? ────────► พอร์ต sealed หลายชุด + graded ล็อต + เกรดผ่าน HK เอง
```

## ✅ กฎเลือกของให้แพง/มีอนาคต (จาก [[ทำไมการ์ด OP TCG ถึงแพง (ปัจจัยราคา)]])
1. **ความหายากจริง > เทียม** — Manga Rare/promo อุปทานจำกัดถาวร
2. **สภาพคือทุกอย่าง** — เกรด 10 vs 9 ราคาต่างหลายเท่า เก็บให้คม
3. **ตัวละครดัง** (Luffy/Zoro/Shanks) = ดีมานด์สูง (Manga Shanks $3,640+ ทั้งที่เล่นไม่ได้)
4. **แยกการ์ดสะสม (นิ่ง) vs การ์ดเล่น (ผันผวนตามเมตา/ban)**
5. **ระวัง reprint** = ศัตรูของราคา

## ⛔ 7 ความผิดพลาดที่มือใหม่ต้องเลี่ยง
1. เปิดบูธจุ่มโดยไม่มีใบอนุญาต (เสี่ยงคุก)
2. ก่อหนี้/ใช้เงินร้อนซื้อการ์ด
3. ไล่ราคาการ์ดที่กำลังไวรัล/พีค
4. ส่งเกรดใบที่ไม่คุ้ม (ลืมกฎ 3-4 เท่า + ลืมบวกภาษีขากลับ)
5. ทุ่มชุดเดียว ไม่กระจาย
6. ลืมต้นทุนแฝง (ค่าส่ง + ประกัน + อากร + VAT 7%)
7. เชื่อว่า "มีข่าว = ราคาขึ้นแน่" (correlation ≠ causation)
