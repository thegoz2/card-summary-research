## 1. Manipulation (ปั่นตลาด)

### 1.1 Buyout / cornering — กว้านซื้อหมดแล้วดันราคา
- **คือ:** คนเดียว/กลุ่มเล็กกว้านซื้อทุกใบในเวลาสั้น → scarcity เทียม → ตั้ง floor ใหม่สูง
- **เคส:** MTG "Moat" (ซื้อหมดในวันเดียว), Eon Hub (วอลุ่ม **20×** + เฉลี่ย **70.5 ใบ/คน**), Pokémon Gouging Fire (**8×** + **13 ใบ/คน**)
- **ดูยังไง:** วอลุ่มพุ่งหลายเท่า + ใบ/คนพุ่ง + listing หายเกลี้ยงแล้วเติมกลับแพงกว่า + **spike ไม่มีเหตุ** (ไม่มีทัวร์/reveal/reprint/ข่าว IP)
- 🔴 **bearish/ปั่น** → ไม่ไล่; ถือ = ขายเข้า spike; ไม่ถือ = รอ 2–4 สัปดาห์ของเติมกลับ

### 1.2 Pump-and-dump (Discord/FB/Reddit รวมหัว)
- **คือ:** สะสมการ์ดถูกเงียบๆ → ปั่นข่าวหลายแพลตฟอร์ม → เทขายเข้า spike
- **ดูยังไง:** mention พุ่งข้ามแพลตฟอร์มของการ์ดไม่มีเหตุ + คนเชียร์มักมีของลิสต์ขายเอง
- 🔴 **bearish** — **spike 20–30% ใน 48 ชม. ที่ไม่มีทัวร์/influencer/data หนุน = สัญญาณ SELL** (อย่าซื้อแท่งเขียว)

### 1.3 Wash trading / comp ปลอม / shill bid
- **คือ:** ขายปลอม/ขายให้ตัวเองดัน "last sold"; ปั่นบิด
- **เคส:** Cardmarket — ปั่น Pikachu Grey Felt Hat ด้วย **200+ บัญชีปลอม** (ฟ้อง ~€12k); eBay แบน PWCC (shill, ลบ **71,000 listing**)
- **ดูยังไง:** ใช้ **Terapeak/sold-paid เท่านั้น**; ผู้ชนะบิด feedback ต่ำ/บัญชีใหม่; auction ปิดสูงกว่าตลาดมาก; ผู้ขายรีลิสต์ซ้ำ "ผู้ชนะไม่จ่าย" = ธง shill
- 🔴 **bearish/ลวง** → discount "last sold" โดย cross-check 5–10 sold หลายแพลตฟอร์ม

### 1.4 Asking-price anchoring (Lorcana Iconic froth)
- **คือ:** ถม listing แพง รีเซ็ต "ราคารับรู้" ขึ้น ทั้งที่ไม่มีใครขายได้จริง
- **Lorcana:** Buzz Iconic market ~$3,549 / listing ถึง $5,899; Mickey Iconic ~$2,000 — **ช่องว่าง market vs paid = ธง anchor**
- **ทำ:** คิด buy/sell จาก **median ของ paid sales ล่าสุดหลายรายการ** ไม่ใช่ listing

## 2. Hype / FOMO

### 2.1 Preview/spoiler premium — pump ตอน reveal แล้วร่วงหลังวาง
- spike ก่อนซื้อได้ → **ร่วง 50–80% หลังวาง** (supply ทะลัก) | Pokémon: Marshadow IR $90→<$13
- 🔴 **อย่าซื้อ preview/prerelease** → รอ 2–6 สัปดาห์หลังวาง (correction -10 ถึง -25% แม้ตัวชนะ)
- ⚠️ **Lorcana wrinkle:** ชุด supply ตึง (Fabled) **หักกฎ "ร่วง"** — chase ไต่ต่อเพราะของหมด

### 2.2 Influencer effect — YouTuber/streamer เปิด/พูดถึง → spike
- Pokémon: PokeBeard → Raichu **+40–47%/10 วัน**; creator 50k+ follower → **12–25%/72 ชม.** (ถ้ามี meta หนุน) | hype แหล่งเดียว **จางใน ~4 วัน**
- ❌ Lorcana-specific = NOT FOUND แต่กลไกเดียวกัน → **fade single-source spike** ถ้าไม่มี meta/IP หนุน

### 2.3 Set-launch FOMO (วงจร 0–3 สัปดาห์)
- pre-release: +15–35% → release euphoria: peak แล้ว **-10 ถึง -25%** → meta validation: ±20–40% → stabilize +5–15%/เดือน
- ดู [[Playbook เก็งกำไร Lorcana — flip-swing-hold + timing]] (ขายเข้า hype / ซื้อ valley สัปดาห์ 3–6)

## 3. Event-driven (มีเหตุพื้นฐาน)

### 3.1 ผลทัวร์/meta — เด็คชนะ → singles ตัวหลักพุ่ง
- foil/Enchanted/Iconic พุ่ง **30–60% ใน 48 ชม.**; สัญญาณมา **12–24 ชม. หลัง** Regionals/Challenge
- Lorcana: "We Know the Way" foil พุ่งทุกครั้งที่เด็ค Monstro combo โผล่; Rhino Power Hamster "ระเบิด"
- 🟢 **bullish มีพื้นฐาน** — แต่ **foil/premium ขยับสุด** (base แทบไม่ขยับ) → **ซื้อ base playable ถูกกว่า** อย่าไล่ foil พุ่ง

### 3.2 Reprint announcement crash
- ประกาศ reprint = ลบพรีเมียมของพิมพ์เดิมเกือบทันที (Pokémon ~-15%)
- **Lorcana โครงสร้างใหญ่:** Fabled = **reprint 171/204 ใบ** → early-set non-premium singles มี **reprint overhang ค้าง** | premium (Enchanted/Iconic) ปลอดภัยกว่า (ไม่ค่อย reprint)
- → ขาย staple ที่ rotate-but-playable **ก่อน** ชุด reprint เปิด; ถือเฉพาะ premium

### 3.3 Rotation panic — เทขายก่อน rotation
- ก.ย. 2025 (Sets 1–4 ออก) ทำ Enchanted ตก **แต่สั้น** (Simba ไต่กลับ ~$200) | Fabled reprint + Infinity format ช่วยพยุง
- 🟢 **panic ของการ์ด collector (ตัวละครดัง) = buy-the-dip** (collector ไม่สน legality) | 🔴 **panic ของ pure playable = ขายก่อน**

### 3.4 Grading pop-report signal
- pop พุ่ง = supply เกรดเพิ่ม = holder เทขาย = 🔴 **bearish** | pop ต่ำ/นิ่ง + demand ขึ้น = 🟢 bullish
- → ขาย graded **ก่อน** pop บวม; อย่าเกรด-ถือการ์ดที่ pop พุ่งเร็ว (มาช้า)

### 3.5 หนัง live-action / ข่าว IP — 🌟 edge เฉพาะ Lorcana
- Disney collector (ไม่เล่น) เข้าตลาด → **"spike ไม่ใช่ trend"** | Moana hype, Frozen 3, Mickey/Stitch
- 🟢 **bullish + edge ที่ Pokémon/MTG ไม่มี** → **pre-position ก่อนข่าว** (ดู [[อันดับความนิยมตัวละคร Disney + นัยต่อ Lorcana]] — Maui/Moana ก.ค. 2026)
