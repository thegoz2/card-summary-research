## 1. ของปลอม Lorcana มีไหม — มี แต่ "ระดับล่าง"

- **PSA Fraud Report 2025:** จัดอันดับถูกปลอมสุด = Pokémon #1 → baseball/basketball/football → Yu-Gi-Oh! → MTG → **Lorcana** → One Piece → ... → **Lorcana อยู่ท้ายๆ top-10** (น้อยกว่า Pokémon/YGO/MTG มาก) ✅
- เทียบสเกล: Pokémon ปลอม +125% YoY, PSA สกัดของปลอม ~$200M → **Lorcana ปัญหาเล็กกว่ามาก** (เกมใหม่ เปิด ส.ค. 2023)
- **ของปลอมกระจุกที่ 2 จุด:** (1) **Enchanted/Iconic chase singles** (คุ้มปลอม — Elsa Enchanted เคยขาย ~$45,000) (2) **sealed box ที่ถูกแกะ/reseal** — **ไม่ใช่** ในซองแท้
- ⚠️ Ravensburger **ไม่มีระบบ verify กันปลอมทางการ** ที่เชื่อถือได้

## 2. Proxy ≠ Counterfeit
- **Proxy** = ตัวแทนเพื่อเล่น/เทสเด็ค, **ดูต่างชัด** (หลังต่าง/มีคำว่า PROXY) ไม่ตั้งใจหลอก — เล่นส่วนตัวได้ ห้ามในทัวร์
- **Counterfeit** = ทำให้เหมือนเป๊ะ **ขายหลอกว่าแท้** = ผิดกฎหมาย (ละเมิดลิขสิทธิ์ + ฉ้อโกง) → **อันตรายสำหรับคนซื้อ**

---

## 3. ดู single แท้/ปลอม

**Lorcana-specific (ยืนยัน):**
| จุดเช็ก | ของแท้ |
|---|---|
| **ขนาด** | 2.5 × 3.5 นิ้ว (63.5 × 88.9 มม.) หนามาตรฐาน TCG — เพี้ยน = ธงแดง |
| **ขอบตัด** | เรียบคม — ปลอมมัก **ขอบหยัก/ไม่เรียบ** (ดูง่ายสุด) |
| **คุณภาพพิมพ์** | คม สีตรง — ปลอก **ฟุ้ง/สีเพี้ยน**; เช็ก **โลโก้ Lorcana + ไอคอน rarity** (ปลอมมักไม่ตรง) |
| **เนื้อกระดาษ** | สัมผัสแบบ TCG แท้ — ปลอม "รู้สึกต่าง" (บาง/ลื่นเกิน) |
| **ไส้สีน้ำเงิน (light test)** | ส่องไฟแรง — แท้ **ทึบ** (แสงผ่านน้อย); ฉีกแล้วเห็น **core สีน้ำเงิน-เทา**; ปลอมมัก **ขาวกว่า + แสงผ่านมาก** ⚠️ |
| **ฟอยล์ Inkwash (Enchanted)** | textured มีมิติ — ปลอม **แบน/พิมพ์ติด** ⚠️ |

**หลัก TCG ทั่วไปเสริม:** loupe 10× ดู **rosette dot** (แท้ละเอียดสม่ำเสมอ / ปลอมหยาบ-pixelated) · เทียบ font/หลังการ์ดกับใบแท้

> [!warning] ⚠️ Lorcana มี QC แปรปรวนสูง (สีไม่เท่ากันในกล่องเดียว, miscut) → **"ใบดูแปลก" อาจเป็นของแท้** อย่าตัดสินจากจุดเดียว — ใช้หลายจุดรวม + เทียบใบแท้

## 4. Sealed box — ความเสี่ยงใหญ่กว่า single (Lorcana-specific!)

> [!danger] First Chapter Wave One มี "ช่องโหว่ออกแบบ"
> box **ไม่ shrink-wrap** + **สไลด์ซองออกได้โดยไม่ฉีกซีล** → คนขายชั่งน้ำหนัก/คัด/สลับซองแล้วใส่กลับได้

**วิธีเช็ก sealed:**
- ✅ เลือก **box พิมพ์ครั้ง 2+ ที่ shrink-wrap** (reprint เพิ่มเทป tamper-evident ที่ขอบ)
- ✅ **24 ซองในกล่องต้องมี pack code เดียวกัน** (โค้ดหลังซอง) — ต่างกัน = สลับมาจากหลายกล่อง
- ✅ **CM date code** บนกล่อง: `MMDDYY + CM + run` เช่น `050123CM1` = พิมพ์ 1 พ.ค. 2023 ("CM" = Cartamundi) → เช็กวันที่สมเหตุผล
- ⚠️ pack code ตรง **พิสูจน์แค่มาจาก batch เดียว ไม่ได้พิสูจน์ว่าไม่ถูกแกะ/สลับ** → ดูเทป/รอยกาวซ้ำ/รอยขูดที่ขอบกล่อง

## 5. Slab graded ปลอม (PSA/CGC)

| จุดเช็ก | วิธี |
|---|---|
| **UV blacklight (PSA)** | label แท้มี "PSA" เรืองสม่ำเสมอตำแหน่งคงที่; ถ้า**เรืองขาวจ้าทั้ง label = ปลอม** |
| **"PSA" นูน** | แท้ขึ้นรูปนูนในพลาสติก — ลูบแล้วรู้สึก; ปลอมพิมพ์แบน |
| **sonic-weld / flex** | เคสแท้เชื่อม ultrasonic **แข็ง ไม่งอ**; ปลอม/แกะ **งอได้ มีฝ้าขุ่นตะเข็บ/ช่อง** |
| **label โปร่ง** | ส่องไฟ — แท้เห็นทะลุจางๆ; label ปลอมแปะทับ **ทึบเกิน** |
| **cert lookup + รูป** | เช็กเลข cert PSA/CGC **แต่ปลอมใช้เลขจริงซ้ำได้** → **เทียบรูปจาก grader** (centering/ตำหนิ) ต้องตรง |
| **ราคา** | ต่ำกว่าตลาดมาก / รูป label เบลอ / ไม่ยอมบอกเลข cert = scam |

---

## 6. คำแนะนำคนไทย (ซื้อมือสอง/นำเข้า)
1. **ซื้อจากแหล่งน่าเชื่อถือ** (ร้านตั้งหลักแล้ว/คอมมูนิตี้เช็กรีวิว) — เลี่ยงคนแปลกหน้า marketplace สำหรับของแพง
2. single: ขอ**รูปหน้า-หลัง-ขอบชัด** + เช็กขอบ/แสง/loupe/โลโก้เอง — เน้น **Enchanted/Iconic** (ที่ปลอมอยู่)
3. sealed: ยืน **shrink-wrap 2nd-run+, 24 code ตรง, CM date, เทป tamper** (ระวัง Wave One)
4. slab: cert lookup + เทียบรูป + UV/flex/นูน
5. **"ถูกเกินจริง" = สัญญาณ #1** ทุกแหล่งตรงกัน
6. นำเข้า: ของปลอม = ปัญหา IP/ศุลกากร + "ไพ่" สรรพสามิต → ดู [[นำเข้า Lorcana มาขายในไทย คุ้มไหม — landed cost (มิ.ย. 2026)]]
