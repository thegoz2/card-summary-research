# การเก็บรักษา Lorcana (สภาพอากาศไทย)

> [!info] โน้ตนี้คืออะไร
> เก็บการ์ด Lorcana ในไทย (ร้อน-ชื้น 70–90% RH) — Lorcana **เปราะกว่าการ์ดทั่วไป** เพราะกระดาษยุโรปขอบขาวง่าย + ฟอยล์ Enchanted ขูดง่าย
> ระดับ: ✅ VERIFIED · ⚠️ PARTIAL

## 1. ความชื้นไทย = ศัตรู (Lorcana เปราะเป็นพิเศษ)

> [!danger] Lorcana-specific: กระดาษ Koehler (ยุโรป) ขอบขาวง่าย
> ✅ PreGradeCards: Lorcana ใช้ **European card stock** ที่ "ไวต่อ whitening + รอยกดผิว" กว่า Pokémon/MTG → **ในความชื้นไทยยิ่งหนัก** = ข้อเท็จจริงที่ Lorcana-relevant สุด

| ความเสี่ยง | เกิดเมื่อ |
|---|---|
| **โก่ง/เป็นคลื่น** | RH > ~60% |
| **ฟอยล์ขุ่น/ม้วน/ลอก** | ความชื้นสูง + ร้อน > 29°C (กาวฟอยล์เสื่อม) |
| **ขอบขาว (edge whitening)** | กระดาษยุโรป + ชื้น (Lorcana หนักสุด) |
| **รา** | RH > ~70% (จุดดำ-เขียว มัก**แก้ไม่ได้**) |
| **หมึกซีด** | ร้อน > 27°C |
| **ฟอยล์ Enchanted ขูด** | ขณะหยิบ/สับซอง (Ravensburger แนะใส่ถุงมือผ้าตอนเปิด) |

---

## 2. เป้าหมาย + วิธีเก็บ

> [!success] เป้า: **~45% RH · 18–24°C · ห้องแอร์** (อย่าเก็บโรงรถ/ห้องใต้หลังคา/รถ/ใกล้หน้าต่าง)

| วิธี | รายละเอียด |
|---|---|
| **double-sleeve** | inner penny/perfect-fit + outer (กันชื้น + กันฟอยล์ขูด — สำคัญกับ Lorcana) |
| **toploader / semi-rigid (Card Saver)** | ใบแพง — ลดแรงกดขอบ (semi-rigid = มาตรฐานส่งเกรด) |
| **binder** | หน้า acid-free/PVC-free + **แบบซิป** (สร้าง microclimate) |
| **silica gel / desiccant** | วางในพื้นที่ปิด ไม่แตะการ์ด (~10–20g/พื้นที่ 5–10 แกลลอน) — recharge ได้ |
| **hygrometer** | วัด RH จริง (~350–500฿) อย่าเดา |
| **dehumidifier** | เครื่องลดความชื้นห้อง = ลงทุนคุ้มสุดในภูมิอากาศชื้น |
| **⭐ ตู้กันชื้น (dry cabinet)** | แบบกล้อง/เลนส์ที่ขายเกลื่อนในไทย — hygrometer + คุมชื้นอัตโนมัติ = **gold standard สำหรับไทย** |

---

## 3. Sealed box ระยะยาว
- เสี่ยง โก่ง/รา/shrink เหนียว + แสง UV ทำอาร์ตกล่องซีด → เก็บ **40–50% RH, 18–24°C, มืด**
- ใส่ **กล่องลม/ลังฝาล็อก + silica gel** หรือ **เคส acrylic แม่เหล็ก 8mm** (กันกระแทก/ฝุ่น/UV)
- ⚠️ **First Chapter Wave One ไม่ shrink-wrap** = ไม่มีเกราะกันชื้น/UV → ต้องป้องกันพิเศษ (ถุง + desiccant + ลังปิด)

## 4. Slab graded
- ⚠️ **slab ไม่ได้ปิดสนิท** — ความชื้นซึมเข้าได้ → ฝ้าใน/มุมยก/รา (มัก**แก้ไม่ได้**)
- ระวัง **ควบแน่น** ตอนอุณหภูมิ/ชื้นเปลี่ยนเร็ว (เช่นพัสดุเย็นเข้าห้องร้อน) → ปล่อย acclimate ก่อนแกะ
- เก็บ ~45–55% RH, 15–21°C + desiccant; เฝ้า ฝ้า/label โก่ง/กลิ่นอับ

---

## 5. ซื้ออุปกรณ์ที่ไหน (ไทย)
| ของ | ที่ | ราคาประมาณ |
|---|---|---|
| **ตู้กันชื้น 30L auto** (Digilife MRD, Ailite ALT-30) | ZoomCamera, JIA, SeedCamera, Lazada, Shopee | ~2,000–4,000฿ ⚠️ |
| toploader/sleeve/กล่อง | TCG Thailand, VG Card Shop, Inkable, Lazada/Shopee | หลักสิบ-ร้อย |
| silica gel/hygrometer/dehumidifier | Lazada, Shopee, PowerBuy | hygrometer ~350–500฿; dehumidifier หลักพัน |

> [!tip] เซ็ตอัปแนะนำ (ตามลำดับความสำคัญ)
> 1. เก็บในห้องแอร์ · 2. ซื้อ hygrometer · 3. **ตู้กันชื้นตั้ง ~45% RH** (คอลเลกชันหลัก) · 4. double-sleeve + toploader ใบแพง · 5. ลังลม + silica สำหรับ sealed/bulk · 6. dehumidifier ถ้าเก็บเยอะ
