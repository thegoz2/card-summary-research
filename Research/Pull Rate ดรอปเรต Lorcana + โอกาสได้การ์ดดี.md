## 1. โครงสร้างซอง/กล่อง (math พื้นฐาน) ✅

| รายการ | ค่า |
|---|---|
| การ์ด/แพ็ก | **12** |
| สล็อต | **6 common + 3 uncommon + 2 rare-ขึ้นไป + 1 foil** |
| แพ็ก/box | **24** |
| box/case | **4** (= 96 แพ็ก/case) |

> [!warning] หัวใจ: "foil slot" สล็อตเดียวคือทุกอย่าง
> 1 foil/แพ็ก แบบสุ่ม rarity — ใส่ได้ตั้งแต่ common foil ถึง Legendary foil **และ chase ทั้งหมด (Enchanted/Epic/Iconic) ก็ใช้สล็อต foil นี้สล็อตเดียว** (ไม่มีสล็อตแยก) → การได้ chase = "แทนที่" foil ธรรมดา ดังนั้นใน box 24 แพ็ก foil ส่วนใหญ่เป็น common/uncommon, chase เป็นเศษเสี้ยว

**Rarity ladder 8 ระดับ (เรียงหายากขึ้น):** Common → Uncommon → Rare → Super Rare → Legendary → **Epic** → Enchanted → **Iconic**

## 2. โอกาสต่อ rarity (community-estimated)

| Rarity | โอกาส (ประมาณ) | ที่มา / ระดับ |
|---|---|---|
| Rare | ~1 ใบ/แพ็ก ขึ้นไป | ✅ (โครงสร้าง) |
| Super Rare | ~1 ใน 2 แพ็ก (~50%) | ⚠️ (Card Gamer/DigitalTQ 55.7%) |
| Legendary | ~1 ใน 5 แพ็ก (~20%); ชุดเก่า ~4–5/box, ชุดใหม่ ~6/box | ⚠️ (หลายแหล่งตรงกัน) |
| **Epic** (ตั้งแต่ Fabled) | **~1–2 ใบ/box** (18 ใบ/ชุด) | ⚠️ (box data) |
| **Enchanted** | **~1 ใน 96 แพ็ก (~1/case)** ชุดเก่า; เปิดจริง 1.2–2.0%/แพ็ก | ⚠️ (น่าเชื่อสุด) |
| **Iconic** (ตั้งแต่ Fabled) | **~1/case หรือหายากกว่า** (2 ใบ/ชุดเท่านั้น; ~1 ใน 1,500 แพ็ก) | ⚠️ |

## 3. ดรอปเรตเปลี่ยนตามเวลาไหม? — **ใช่ ใจป้ำขึ้น** ⚠️

- **ชุด 1–4 (Classic):** Enchanted แน่น ~1/96 แพ็ก, ทั้ง case ไม่มี Enchanted = เรื่องปกติ
- **ชุด 5–8:** ~5 Legendary/box, "clumping"
- **ชุด 9+ (Fabled+):** เพิ่ม Epic (~1–2/box), Legendary ขึ้น ~6/box, Enchanted หลวมขึ้น
- **Wilds Unknown (ชุด 12):** **ใจป้ำชัด — Enchanted ใน 4 จาก 8 box (~1/2 box)** เทียบ Winterspell (ชุด 11) ที่ทั้ง case บางอันมี 0 Enchanted

> consensus community: Ravensburger ปรับให้ "ประสบการณ์เปิดซองดีขึ้น" — แต่ variance ยังสูง + sample เล็ก

---

## 4. EV ของการเปิด box (OPINION)

> [!fail] เปิด box หวังกำไร = -EV เกือบเสมอ
> - box (~$144, 24 แพ็ก) คาดได้ ~6 Legendary + ~2 Epic + **~0.5 Enchanted** (ชุดใหม่) + bulk — ส่วนใหญ่ Legendary/Epic ราคาไม่กี่ดอลลาร์ถ้าไม่ใช่ตัว meta/chase
> - **OPINION:** box ชุดใหม่คืนทุนเป็น single ราว **20–35% ของกล่อง**; ส่วนใหญ่คืน ~50–80% ของราคา
> - **ไล่ Iconic ด้วยการเปิด = แพงกว่าซื้อ single มหาศาล** (Wilds Unknown Buzz ~$2,882 — ซื้อใบเดียวถูกกว่าเปิดเป็นลัง)
> - 👉 **อยากได้ตัวไหน ซื้อ single; อยากเก็งกำไร ถือ sealed/single ไม่ใช่ฉีกกล่อง**

---

## 5. โอกาสได้ "เกรดสวย" (gem-mint) ⚠️

- Enchanted pack-fresh ติด **PSA10 ~40–55%** (⚠️ ประเมินรายเดียว PreGradeCards) → **เกือบครึ่งไม่ติด gem-mint**
- ตัวฆ่า: **edge/corner whitening #1** (กระดาษยุโรปขอบขาวง่าย), **print line #2** (cap 8–9), foil scratch
- 👉 ต้องคิด EV ถ่วงน้ำหนัก + คัดสภาพก่อนส่ง → [[กลยุทธ์ส่งเกรด Lorcana (PSA-CGC) + ส่งจากไทย]]

---

## 6. promo / special (scarcity แท้) ✅

- **D23 Expo 2022 promo:** ชุด foil 6 ใบ (3 hero/3 villain) — set ครบ **$5,000+** บน eBay ภายในไม่กี่วัน (~100× ราคาออก)
- **Mickey – Brave Little Tailor** (แจกแบบ non-foil) = **least scarce** (graded 1,000+ ใบ)
- cold-foil / championship promo: ❌ ไม่มี print-run เปิดเผย (อนุมานจาก graded pop)
