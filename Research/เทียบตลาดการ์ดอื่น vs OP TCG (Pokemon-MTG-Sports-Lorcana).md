## 1. สรุปผู้บริหาร

- ตลาดการ์ดสะสมโลก 2026 ~**USD 8-15 พันล้าน/ปี** (ประเมินยาก): **Pokémon นำ ~$2.9B** · **MTG ฟื้นแรง $1.72B (+60%)** · **OP TCG อันดับ 3** (Bandai card games รวม ~$1.99B)
- **OP TCG อายุแค่ 4 ปี** (เปิด ก.ค. 2022) vs Pokémon 30 ปี / MTG 32 ปี → อยู่ช่วง **"Expansion ปลาย → Distribution"** คล้าย Pokémon ปี 2020-21 ก่อนฟองสบู่
- **บทเรียนสำคัญสุด:** (1) ตลาดไม่มีกลไกคุม supply (ไม่มี Reserved List แบบ MTG) ผ่านบูม-แตก-ฟื้น**ซ้ำเสมอ** (2) ฟองสบู่ Pokémon/sports 2020-21 ร่วง 35-80% แต่รอดผ่าน blue-chip ที่ scarcity แท้ (3) Lorcana เตือนว่า hype นักเก็งกำไรในตลาดใหม่**ดับปีที่ 2-3 เสมอ**
- **OPINION:** ควรมอง OP TCG เป็น **"ตลาดเก็งกำไรผสมสะสม เสี่ยงสูง"** ไม่ใช่สินทรัพย์ลงทุนยาวแบบ vintage MTG/baseball

## 4. บทเรียนจากแต่ละตลาดต่อ OP TCG

**🟡 Pokémon (ราชาที่ยังครองบัลลังก์):** 2020-21 Charizard PSA10 $15K→$75K→$17K (−77%) จาก stimulus หมด + over-print → **บทเรียน:** over-print = kill switch เร็วสุด แต่ Pokémon รอดเพราะ IP อมตะ + ฐานแฟนยักษ์; **OP เสี่ยงกว่า** เพราะฐานเล็กกว่า + IP จะจบ — แต่ blue-chip ที่ scarcity แท้ (OP-01 wave1, MR ชุดต้น) อาจฟื้นแบบ Charizard

**🔵 MTG (ผู้รอดด้วย Reserved List):** Chronicles 1995 reprint ทำการ์ด $50→$2 → กำเนิด **Reserved List** (ห้าม reprint) → Black Lotus $3M; **บทเรียน:** Reserved List = ประกันราคา vintage **OP ไม่มี = systemic risk ใหญ่สุด** (Bandai reprint OP-01 ได้ทุกเวลา); Universes Beyond (+60%) พิสูจน์ว่า IP crossover ดึงนักสะสมใหม่ได้ (OP ทำคล้ายผ่าน Netflix)

**⚾ Baseball (ฟองสบู่ชัดสุด):** 2021 modern cards +300-1500% → −50-80% ใน 2022 แต่ **vintage (Mantle $12.6M) แยกตัวรอด**; **บทเรียน:** modern sports = TR/SP ชุดใหม่ OP ที่ร่วง 30-40% หลังวาง **เป๊ะ**; vintage = sealed OP-01/MR แต่ต้องมีแฟนฐานนานพอ (baseball 70 ปี); การ์ดกีฬาพึ่งนักกีฬาจริง (legacy ถาวร) ต่างจาก OP พึ่งตัวละครสมมติ (IP ตายได้)

**⚽ Soccer (ขับด้วยนักเตะ):** Messi PSA10 $1.5M, Topps แทน Panini ใน PL (+4x = $1.6B); **บทเรียน:** IP ฐานแฟน 4 พันล้าน (FIFA) ยั่งยืนกว่า anime; **World Cup 2026 จะแย่ง attention/งบ** จากตลาด collectibles รวม OP ด้วย

**🏰 Lorcana (เตือน hype cycle):** เปิด 2023 ขาย >1B ใบปีแรก → 2025 ยอดลด "**speculator ที่เข้ามาเพราะ hype ถอนหมดแล้ว**" (Ravensburger); **บทเรียน:** กรณีศึกษาชัดสุดว่า hype bubble TCG ใหม่**ดับปีที่ 2-3** — OP ปี 2025-26 อยู่ช่วงเดียวกันเป๊ะ; คู่แข่งใหม่ (Lorcana/Gundam/Digimon) แย่ง wallet share — total TCG spending ไม่ได้โตตามจำนวนเกมที่ออก

## 5. OP TCG Positioning (SWOT เทียบตลาดอื่น)

| | |
|---|---|
| **💪 Strengths** | IP One Piece แฟน 100M+ (27 ปี) · อันดับ 3 โลกใน 4 ปี · competitive scene แข็ง (แชมป์โลกคนไทย 2026) · entry price ยังสมเหตุผล |
| **⚠️ Weaknesses** | **ไม่มี Reserved List** · **IP จะจบ (Final Saga)** · อายุ 4 ปี ยังไม่ผ่าน crash เต็ม · speculator ~75% · grading/market เล็กกว่าเจ้าอื่น · สูงสุด $24K ยังไม่มี landmark |
| **🚀 Opportunities** | Final Saga FOMO · simultaneous global release ขยายฐาน · Netflix S2 ดึง demographic ใหม่ · grading ecosystem โต · World Cup crossover |
| **🔴 Threats** | **Bandai reprint = catastrophic** (แบบ MTG Chronicles) · คู่แข่งแย่ง wallet · เศรษฐกิจกระทบ discretionary · 75% speculator ถอนพร้อมกัน = −40-70% · One Piece จบ + ไม่มี IP ต่อ |

## 6. นัยต่อนักลงทุนไทย

> [!check] FACT: ทุกตลาดการ์ดผ่านบูม-แตก-ฟื้น ไม่มีตลาดไหนขึ้นตลอด (MTG 1995 / Pokémon 2021 / sports 2022 / Lorcana 2025) · ของแพงสุดทุกตลาดมาจาก scarcity แท้ + แฟนฐานหลายสิบปี — OP อายุ 4 ปียังไม่มีเวลาสร้าง "legend"

### ความน่าลงทุนสำหรับคนไทย (OPINION ไม่ใช่คำแนะนำการเงิน)
| ตลาด | น่าลงทุน | เหตุผล |
|---|---|---|
| **OP TCG blue-chip** (sealed OP-01, MR PSA10) | ⭐⭐⭐ | เข้าถึงได้ + scene ไทยแข็ง — แต่ไม่มี Reserved List, IP จะจบ |
| **Soccer cards** (Messi/Mbappe PSA) | ⭐⭐⭐ | IP จริง + World Cup 2026 catalyst — liquidity ไทยต่ำ |
| **Pokémon vintage** | ⭐⭐ | IP อมตะ แต่ทุนสูงเกินงบคนไทยส่วนใหญ่ |
| **MTG Reserved List** | ⭐⭐ | ค้ำราคาดี แต่ liquidity ไทยต่ำมาก ต้องรู้ลึก |
| **Lorcana / Baseball vintage** | ⭐ | ตลาดไทยเกือบไม่มี / ไม่คุ้น |
| **OP TCG flip TR/SP ชุดใหม่** | ⭐ | เสี่ยงสูงมาก −30-50% ใน 4-8 สัปดาห์ |

### กระจายพอร์ต (OPINION)
1. **Core OP TCG 40-50%** — blue-chip เท่านั้น (sealed OP-01/02/03, MR PSA10 ตัวหลัก, Leader Alt-art) ห้ามถือ TR/SP ชุดใหม่ยาว
2. **Soccer Messi/Mbappe PSA10 10-20%** — World Cup 2026 catalyst, กระจาย asset ออกจาก anime (ขายผ่าน eBay/intl)
3. **เงินสด 30-40%** — Distribution Phase รอผล OP-17 (ส.ค. 2026): พัง = ซื้อ blue-chip ถูก / ไม่พัง = ยืนยัน demand ค่อยเพิ่ม
4. **MTG/Lorcana** — ไม่เหมาะนักลงทุนไทยทั่วไป (liquidity ต่ำ)
