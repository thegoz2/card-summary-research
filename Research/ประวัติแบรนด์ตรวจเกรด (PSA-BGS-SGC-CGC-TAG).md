## 1. กำเนิด third-party grading (ปลายยุค 90s) ✅
- ก่อนมีเกรด: ปลอม/trim ขอบ/เถียงสภาพกันมั่ว ("bent corner" ก็เรียก mint) → ต้องมีคนกลางให้ baseline
- **โมเดลมาจากเกรดเหรียญ:** PCGS (1986) คิด slab tamper-evident + เกรด → PSA (การ์ด) + CGC (คอมิก) เอามาใช้ = เปลี่ยนจาก **raw → slabbed**
- **catalyst = ปี 1998:** ศึกโฮมรัน McGwire–Sosa ปลุกวงการ + **eBay** (ซื้อออนไลน์เห็นการ์ดจริงไม่ได้) → grade คนกลางกลายเป็นสิ่งจำเป็น

## 2. 🥇 PSA (1991) — ผู้ครองตลาด ✅
- **David Hall** (เจ้าของ PCGS เหรียญ) ตั้ง ก.ค. 1991 — ช่วงแรก **ดิ้นรนหนัก** (1991–98 เกรดแค่ ~1M ใบ เคยคิดจะปิด)
- **1–10 scale** (10 Gem Mint) = benchmark อุตสาหกรรม | การ์ดแรก = T206 Honus Wagner (NM-MT 8) ⚠️
- **Collectors Universe** (1999, IPO NASDAQ "CLCT") → **take private 2021 (~$700M)** นำโดย **Nat Turner** (+ D1 Capital + Steven Cohen เจ้าของ Mets) → เปลี่ยนชื่อ **Collectors / Collectors Holdings**
- บูม 2020–21 → backlog ~10–12M → **2021 หยุดรับ Value tier + ขึ้นราคา 2 เท่า** (ประวัติศาสตร์ซ้ำปี 2026)

## 3. 🔬 BGS / Beckett ✅
- **Dr. James Beckett** (อาจารย์สถิติ) ทำ **price guide ตั้งแต่ 1979** → Beckett Baseball Monthly (1984, พีค ~1M เล่ม/เดือน) = เจ้าราคาวงการ
- **BGS ~1999** ⚠️ (Baseballcardpedia ว่า 2000) → นวัตกรรม **4 subgrade** + **Black Label** (4 subgrade = 10.0 ทั้งหมด)
- **สายเจ้าของ:** Apprise Media (2005) → Eli Global (2008) → Collēctīvus → **Collectors/PSA (ธ.ค. 2025)** | ❌ "Shanda Games เคยถือ Beckett" = NOT FOUND (ไม่จริง)

## 4. SGC (1998) ✅
- ตั้ง ก.ค. 1998 = คู่แข่งจริงรายแรกของ PSA — เด่น **vintage sports** + **tuxedo slab** (ขอบดำกรอบการ์ด)
- **Collectors ซื้อ ก.พ. 2024** → ภายหลังประธานออก, ทรัพยากรย้ายไป PSA, volume ลด ~24% ปี 2025 ⚠️
- ⚠️ Wikipedia เรียกผิดเป็น "CSG 2023" — ที่ถูกคือ **SGC, ก.พ. 2024** (CSG เป็นแบรนด์ย่อยของ CCG คนละเจ้า)

## 5. CGC / CCG ✅
- **4 ม.ค. 2000** (Steve Borock, New Jersey) — **กำเนิดจากเกรดคอมิก** (CGC คิด slab คอมิกมาตรฐาน) ใต้ร่ม **CCG** (Certified Collectibles Group, 1987)
- **ขยายสู่การ์ด ~2018** (CGC Cards) + Pokémon ~2019 → submission ระเบิด 2020–21 → กลายเป็นค่าย **anime/TCG-friendly** (มรดกคอมิก/ภาพประกอบ)
- **Blackstone ซื้อหุ้นใหญ่ CCG (1 ก.ค. 2021, >$500M)** ร่วมกับ **Roc Nation (Jay-Z), Michael Rubin (Fanatics)** ฯลฯ

## 6. 🤖 TAG (~2020–2022) ⚠️
- ค่าย **AI/computer-vision** ใหม่ — **Steve Kass** ตั้ง (หลังลูกถามเรื่องคอลเลกชัน 400,000+ ใบ), ฐาน **แคนาดา**
- เทค: Photometric Stereoscopic Imaging + ML สแกนตำหนิ "ไร้อคติมนุษย์" → pitch = **objective/โปร่งใส/reproducible** + รายงานตำหนิรายใบ
- ⚠️ ปีก่อตั้งคลุมสุด (บริษัทว่า "launched 2022", บางลิสต์ว่า 2020)

---

## 7. 🏛️ การควบรวมของ Collectors = เรื่องใหญ่ยุค 2020s ✅
> [!warning] อุตสาหกรรมที่เคยกระจาย → ผูกขาดใน ~5 ปี
> **Nat Turner / Collectors Holdings ซื้อ PSA (2021) + SGC (ก.พ. 2024) + Beckett (ธ.ค. 2025)** = **3 ใน 4 ค่ายใหญ่ดั้งเดิม อยู่เจ้าเดียว ~80% ตลาด** (PSA เดี่ยวๆ ~70% ก่อนหน้า)
> - **FTC demand (ส.ส. Pat Ryan, ธ.ค. 2025)** — สอบ Collēctīvus เป็น "pass-through" เลี่ยงการตรวจ merger + SGC ถูกลดบทบาท
> - **antitrust suit (Rasmussen v. Collectors, เม.ย. 2026)** — กล่าวหา SGC ขึ้นราคา +20%/turnaround +400% หลังถูกซื้อ + PSA ขึ้นราคาพร้อมกัน ⚠️
>
> **เหลือ independent: CGC (Blackstone) + TAG** = 2 ทางเลือกที่ไม่อยู่ใต้ Collectors → สำคัญถ้าห่วง price/competition อนาคต

## 8. ไทม์ไลน์บูม
- **2020–21:** lockdown + stimulus + nostalgia → submission ทุบสถิติ, PSA backlog 10–12M → **2021 หยุด Value + ขึ้นราคา**
- **2025–26:** PSA เกรด 19M+ ใบ/ปี, ประกาศลงทุน $200M → submission พุ่ง 20% (+1.6M) → backlog กลับ 10M → **หยุด Value tier 2 มิ.ย. 2026** (= ซ้ำรอย 2021 แต่ตอนนี้อยู่ในโครงสร้างกึ่งผูกขาด)

## นัยต่อนักลงทุน Lorcana (OPINION)
1. **PSA ครองด้วยประวัติ + scale 1–10 ที่เป็นมาตรฐาน** → resale สูงสุด (เหตุผลเชิงประวัติศาสตร์)
2. **CGC มรดกคอมิก/ภาพประกอบ** → เลยเป็นค่าย anime/TCG-friendly ที่ครองปริมาณ Lorcana
3. **ระวัง concentration risk** — PSA+SGC+Beckett เจ้าเดียว = ราคา/turnaround มีความเสี่ยงเชิงนโยบาย (เห็นแล้วจาก Value pause + คดี); CGC/TAG = independent
