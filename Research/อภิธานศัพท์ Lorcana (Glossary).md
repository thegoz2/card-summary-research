# อภิธานศัพท์ Lorcana (Glossary)

> [!info] โน้ตนี้คืออะไร
> ศัพท์/กลไก Lorcana อธิบายง่ายๆ — อ่านควบคู่โน้ตอื่น (โดยเฉพาะตอนดู chase card หรือเล่นจริง)

## 🎴 พื้นฐานเกม

- **Lorcana** — TCG เกมแรกของ **Ravensburger** (เยอรมัน) ร่วมกับ Disney, ออกแบบโดย **Ryan Miller**, เปิด ส.ค. 2023 ✅
- **Illumineer** — ตัวผู้เล่น ("ผู้ร่ายหมึก" เรียกตัวละครออกมา) ✅
- **Glimmer** — การ์ดตัวละคร Disney ที่ถูกเรียกออกมา (= การ์ดประเภท Character) ✅
- **Lore (เงื่อนไขชนะ)** — แต้มชัยชนะ: **ใครถึง 20 lore ก่อนชนะ** ✅ (variant: Pack Rush = 15, co-op Quest = ทุกคนถึง 20)
- **Quest (เควส)** — exert ตัวละครเพื่อได้ lore เท่าค่า Lore ที่พิมพ์บนการ์ด (วิธีหลักในการได้ lore) ✅
- **Ink / Inkwell** — ระบบทรัพยากร: ลงการ์ด 1 ใบ/เทิร์น **คว่ำหน้า** ลง inkwell → exert เพื่อจ่ายค่าร่าย; ink เป็น pool รวม สีไม่จำกัดว่าจ่ายอะไรได้ ✅
- **Inkable / Uninkable** — ใส่ลง inkwell ได้เฉพาะการ์ดที่มี **ขอบ inkwell** (inkable); ไม่มีขอบ = uninkable ลงเป็น ink ไม่ได้ → สัดส่วน inkable เป็นเรื่อง deckbuilding สำคัญ ✅
- **Exert / Ready** — *Exert* = หมุนการ์ดตะแคง (จ่าย ink/quest/challenge/sing); *Ready* = ตั้งตรงกลับตอนต้นเทิร์น ✅
- **Challenge** — exert ตัวละครเข้าปะทะ ทั้งคู่ทำดาเมจ = Strength; ถูก banish เมื่อดาเมจ ≥ Willpower ✅
- **"drying the ink" / summoning sickness** — ตัวละครที่เพิ่งลงเล่น quest/challenge เทิร์นนั้นไม่ได้ เว้นมี **Rush** ✅
- **Strength / Willpower / Lore** — สเตตัสบนการ์ด Character (พลังโจมตี / พลังชีวิต / แต้ม lore เวลา quest) ✅

## 🎨 6 สี Ink (Inks)

> deck ใช้ได้ **ไม่เกิน 2 สี**, ขั้นต่ำ 60 ใบ, การ์ดชื่อเดียวกันไม่เกิน 4 ใบ ✅

| สี | คาแรกเตอร์เพลย์ (⚠️ ธรรมเนียม community) |
|---|---|
| **Amber** | ป้องกัน/ฮีล/board ทน (Bodyguard + heal) |
| **Amethyst** | จั่วการ์ด/เล่นซ้ำ/tempo (ธีมเวทมนตร์) |
| **Emerald** | กลโกง: discard/banish/กวนมือ |
| **Ruby** | บุกควบคุม: Rush/Reckless ราคาถูก, Strength สูง |
| **Sapphire** | ramp + ตัว value mid/late + item |
| **Steel** | ตั้งรับหนัก: Strength/Willpower สูง, Challenger |

- **Dual-ink card** — การ์ด 2 สี (เปิดตัว Set 7 Archazia's Island, ก.พ. 2025): ลงได้เฉพาะ deck ที่คู่สีตรงเป๊ะ ✅

## 🗂️ ประเภทการ์ด (5 แบบ)

- **Character (Glimmer)** — ตัวละคร อยู่ในสนาม quest/challenge/sing ได้ มีสเตตัส ✅
- **Action** — ใช้ครั้งเดียวแล้วทิ้ง ✅
- **Song** — subtype ของ Action: เล่นได้โดยจ่าย ink **หรือ** exert ตัวละครที่ค่า ≥ ค่า song (ร้องฟรี) ✅
- **Item** — อยู่ในสนาม ให้ความสามารถต่อเนื่อง/กดใช้ ✅
- **Location** — (เปิดตัว Set 3 Into the Inklands) มี Willpower + Move Cost, สร้าง lore เองได้, วางแนวนอน ✅

---

## 🧬 Classification ตัวละคร (Glimmer types)

- **Storyborn** — เวอร์ชัน "ตามต้นฉบับหนัง" ✅
- **Dreamborn** — เวอร์ชัน "what-if" ที่ Illumineer จินตนาการแปลงไป ✅
- **Floodborn** — ตัวที่ถูก **the Flood (หายนะหมึก)** แปลงร่าง = **พก keyword Shift** (วางทับตัวชื่อเดียวกันที่อยู่ในสนาม) ✅

> หมายเหตุ: Hero/Villain/Princess/Captain/Sorcerer ฯลฯ = **subtype/classification** ที่ความสามารถบางใบอ้างถึง ไม่ใช่ origin class

## ⚡ Keyword / ความสามารถ

| Keyword | ความหมาย (1 บรรทัด) | เปิดตัว |
|---|---|---|
| **Bodyguard** | ลงเล่นแบบ exert ได้; ฝ่ายตรงข้ามต้องเลือก challenge ตัวนี้ก่อน (taunt) | Set 1 |
| **Evasive** | challenge ได้เฉพาะตัวที่มี Evasive เหมือนกัน | Set 1 |
| **Rush** | challenge ได้ทันทีเทิร์นที่ลง | Set 1 |
| **Ward** | คู่ต่อสู้ "เลือก" ด้วย action/ability ไม่ได้ (target ได้แค่ challenge) | Set 1 |
| **Challenger +N** | เวลา challenge ได้ +N Strength | Set 1 |
| **Resist +N** | ลดดาเมจที่รับ N (stack ได้) | Set 2 |
| **Shift N** | ถ้ามีตัวชื่อเดียวกันในสนาม ลงตัวนี้จ่าย Shift cost แทน ink cost แล้ววางทับ | Set 1 |
| **Singer N** | นับเป็นค่า N เพื่อร้อง song (แม้ ink cost จริงต่ำกว่า) | Set 1 |
| **Reckless** | quest ไม่ได้ + ต้อง challenge ถ้าทำได้ (บุกบังคับ) | Set 1 |
| **Support** | เวลา quest เพิ่ม Strength ตัวนี้ให้ตัวอื่นที่เลือก | Set 1 |
| **Sing Together N** | song ที่หลายตัวรวมค่า ≥ N ช่วยกัน exert ร้องฟรี | Ursula's Return era |
| **Vanish** | ถูก action ฝ่ายตรงข้ามเล็งเป็นเป้า → ถูก banish แทน | **Set 7 (มี.ค. 2025)** |
| **Underdog** | ถ้าเป็นเทิร์นแรกและเล่นทีหลัง จ่าย ink น้อยลง 1 (catch-up) | **Set 11 (ก.พ. 2026)** |

> ⚠️ Shift มี variant เชิง template (Puppy Shift, shift ตาม classification, shift ชั่วคราว) = การพิมพ์ข้อความต่าง ไม่ใช่ keyword ใหม่แยก

## 🔄 Format & Rotation (สำคัญต่อการลงทุน)

- **Core Constructed** — format แข่งที่ **หมุน (rotating)** เฉพาะชุดใหม่ๆ legal ✅
- **Infinity Constructed** — format **eternal** ทุกชุดตลอดกาล ไม่หมุน (มี banlist แยก) — เปิดพร้อม rotation รอบแรก (Fabled, ก.ย. 2025) ✅
- **Rotation** — หมุน **ทีละ block 4 ชุด, ปีละครั้ง** (ตอนชุดที่ 3 ของปีออก); legal window ≈ **~8 ชุด (~2 ปี)** ✅
  - รอบ 1: **ก.ย. 2025** → Sets 1–4 ออก
  - รอบ 2: **ก.ค. 2026** → Sets 5–8 ออก (กำลังจะถึง)
  - รอบ 3: **~กลางปี 2027** → Sets 9–12 ออก ⚠️ (อนุมาน)
- **reprint relief** — staple หลายใบถูก reprint ในชุดใหม่ → การ์ดยัง Core-legal ต่อแม้พิมพ์เดิม rotate ออก (เช่น Fabled = reprint 171/204 ใบ) ✅

> นัยลงทุน → ดู [[Playbook เก็งกำไร Lorcana — flip-swing-hold + timing]] (rotation = BUY-window มากกว่า SELL)

## 💎 Rarity & คำสะสม/ตลาด

- **Rarity ladder (official):** Common (วงกลมเทา) → Uncommon (หนังสือ) → Rare (สามเหลี่ยมบรอนซ์) → Super Rare (เพชรเงิน) → Legendary (ห้าเหลี่ยมทอง) → **Epic** → **Enchanted** → **Iconic** ✅
- **Enchanted** — chase rarity ดั้งเดิม: borderless alt-art + ฟอยล์ **"Inkwash"**, เลขเกินชุดหลัก (เริ่ม Set 1, 12 ใบ) ✅
- **Epic** — rarity พรีเมียม borderless rainbow foil, ~1 ใบ/box (เปิดยุค Fabled, ปลาย 2025 ⚠️) ✅
- **Iconic** — **ใหม่สุด + หายากสุด** (เปิด Fabled): full-art, ฟอยล์ "Lore Star", hot-stamp 3D, **~2 ใบ/ชุด (~1 ใบ/case)** ✅
- **Inkwash foil** — ฟอยล์พิเศษบน Enchanted + promo D23 2022 ✅
- **D23 promo** — promo จาก D23 Expo (ก.ย. 2022, ก่อนเปิดเกม), Inkwash, หายาก ค่าสะสมสูง ✅
- **Wave One / first print** — ธรรมเนียม: การ์ด/box **พิมพ์ครั้งแรก** ของ The First Chapter (หายาก/แพงกว่า reprint) — ⚠️ ไม่ใช่ป้ายทางการ (ไม่มี 1st-ed stamp)
- **Pull rate** — โอกาสได้ rarity (Ravensburger **ไม่ประกาศ official**; Enchanted ~1/72–96 แพ็ก ~1/case) ⚠️
- **Chase card** — การ์ดที่คนตามหา/มูลค่าสูงสุดในชุด (มัก Enchanted/Iconic ตัวท็อป) ✅ (ธรรมเนียม)
- **Slabbed / graded** — การ์ดที่เกรดแล้วใส่กล่อง (PSA/CGC/BGS + CCC ที่เน้น Lorcana) → ดู [[กลยุทธ์ส่งเกรด Lorcana (PSA-CGC) + ส่งจากไทย]]
- **sold comp vs ask** — *sold comp* = ราคาขายจริง (ใช้ตัวนี้); *ask* = ราคาตั้งขาย (มักเว่อร์ อย่าเชื่อ) ✅

## 🌍 ผู้เกี่ยวข้อง / ตลาด

- **Ravensburger** — ผู้ผลิต (ครอบครัว Maier, เยอรมัน) — ค่าย **anti-scarcity** (ไม่มี Reserved List)
- **Saka Saka** — ตัวแทนกระจาย Lorcana ในเอเชีย/ไทย (ตั้งแต่ ก.ย. 2025) → [[ตลาด Lorcana ในไทย + SEA (มิ.ย. 2026)]]
- **Takara Tomy** — ผู้กระจายเวอร์ชันญี่ปุ่น (ม.ค. 2025)
- **Pixelborn** — client ดิจิทัลแฟนทำ (ถูก Disney สั่งปิด มิ.ย. 2024) — ตอนนี้ Lorcana ยังไม่มีเกมดิจิทัลทางการ
