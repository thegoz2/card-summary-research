# การ์ดปลอม และ วิธีดูของแท้ OP TCG

> [!danger] 🚨 ไม่มีวิธีไหน 100% — ต้องเช็คหลายสัญญาณรวมกัน + เทียบกับการ์ดแท้เสมอ
> ของปลอมระดับสูง ("super fakes") ปี 2025–2026 พัฒนาเร็วมาก | งานวิจัยรอบ 16 (2026-06-16)

← กลับไป [[One Piece TCG - ทำกำไร (ภาพรวม)]] | เกี่ยวข้อง: [[วิธีพรี OP-17 ในไทย]] · [[ฝั่งขาย และ ภาษีกำไรไทย OP TCG]] · [[ชุดไหนน่าเก็บตอนนี้ (กลางปี 2026)]]

## 🔍 ตรวจการ์ดเดี่ยว (single) — 6 จุดหลัก (✅ ยืนยัน)

| จุดตรวจ | การ์ดแท้ | การ์ดปลอม |
|---|---|---|
| **1. หลังการ์ด (สี)** | น้ำเงินสดเข้ม สมดุล | **อมม่วง/ทึบ (purple tint)** — สัญญาณที่เห็นบ่อยสุด |
| **2. ผิวสัมผัส (texture)** | ละเอียดมีมิติ | เรียบ uniform เกินไป / รู้สึกบาง-พลาสติก |
| **3. คุณภาพพิมพ์** | คมทุกตัวอักษรเล็ก | เบลอ/พิกเซลแตก โดยเฉพาะ **copyright มุมขวาล่าง** |
| **4. สี/saturation** | สมดุล | อิ่มเกิน หรือ ซีด/แบนเกิน เพี้ยน off-tone |
| **5. foil/holo** | ฝังในเนื้อการ์ด เอียงแล้วเหลือบไหลธรรมชาติ | เหมือนสติกเกอร์ มันวาวเกิน |
| **6. เนื้อกระดาษ** | แข็ง ดีดกลับได้ (snap back) | นิ่ม/ฟ่าม (spongy) |

> [!tip] 🏷️ Authenticity stamp (✅ ยืนยัน)
> การ์ดแท้บางใบ (เช่น Luffy OP05-119) มี **ตราเล็กเกือบโปร่งใส "One Piece Card Game"** ที่มุมซ้ายล่างใกล้สัญลักษณ์สี → ของปลอมพิมพ์ทื่อ ๆ **ไม่โปร่งใส**
> ⚠️ ตราอาจต่างกันตาม rarity/ชุด — ไม่ future-proof 100%

> [!example] 📌 เคสจริง (CGC, ส.ค. 2024): Luffy OP05-119 Manga Alt Art ปลอม
> ตรวจพบจาก: texture เรียบเกิน · ศิลปะรายละเอียดน้อยลง · หลังอมม่วง · ตัวอักษรหนา/copyright คมน้อย · ตราพิมพ์ทื่อ
> → ใบนี้ ungraded เคยขาย **~$3,000** = ทำไม **การ์ดแพง (Manga Rare/alt-art) เสี่ยงปลอมสูงสุด**

## 🧪 การทดสอบที่ทำเอง (+ ข้อจำกัด)
- **Light test** (ส่องไฟ): แท้แสงทะลุน้อย (กระดาษหลายชั้น) → ⚠️ เป็นแค่ "first-pass" super fakes บางใบพิมพ์ชั้น black core เองจนผ่านได้
- **Rip/black-core test** (ฉีกดูแกนดำ): ทำลายการ์ด ใช้กับใบที่สงสัยจริงเท่านั้น + ให้ false positive ได้

> [!caution] ❌ วิธีที่ "ถูก refute — อย่าใช้"
> - ทดสอบ "ความหนา" (ปลอมหนากว่า) — **refute 0-3** (แท้มี batch variation)
> - infrared test (white vs black tint) — **refute 0-3**
> - กฎตายตัว "แท้ต้องมี texture เสมอ / foil ปลอมต้องสว่างเกินเสมอ" — **refute 0-3**

## 📦 กล่อง/ซอง sealed ถูกแกะ-reseal (✅ ยืนยัน)

**กล่อง booster box:**
- factory seal = บาง เรียบ แม่นยำ
- 🚩 รีซีล = ซีลหนา/ไม่สม่ำเสมอ, **เส้นซีลคู่ขนาน**, เงา "ghost" ของรอยเดิม, พลาสติกตึงไม่สม่ำเสมอ/ขุ่นมัว (heat gun), มุมพับหนาเทอะทะ

**ซองเดี่ยว (pack):**
- ดู **รอย crimp ขอบซอง** → ถ้าไม่สม่ำเสมอ/แบนราบ/**เส้นคู่ (double crimp)** = อาจถูกแกะปิดใหม่

> [!warning] ⚠️ seal สวยไม่การันตีว่าแท้
> มืออาชีพรีซีลแนบเนียนได้ → seal สวยเป็น false negative ได้ | **UV หาคราบกาว seam กล่อง — ถูก refute 0-3 อย่าพึ่ง**

## ⚠️ แหล่งเสี่ยง vs ปลอดภัย

| 🚩 เสี่ยง | ✅ ปลอดภัยกว่า |
|---|---|
| เว็บจีน (AliExpress/DHgate/Temu) | ร้านทางการ/authorized (KIDZ AND KITZ network) |
| ราคาถูกผิดปกติ | ร้านมีหน้าร้าน/รีวิวเยอะ |
| ผู้ขายไม่มีรีวิว / FB คนแปลกหน้า | marketplace มี escrow (Shopee/Lazada) |
| พรีจากร้านไม่น่าเชื่อถือ | **การ์ดแพง → ซื้อแบบ graded (PSA/CGC)** |

> 💡 กฎทอง: **ของแพง (Manga Rare/alt-art/SEC) → ซื้อแบบ graded หรือจากร้านน่าเชื่อถือเท่านั้น** (เคส Luffy ปลอม $3,000 = บทเรียน)

## 🎓 ส่งเกรด = ตัวกรองของปลอม (แต่ไม่ 100%)
- PSA/CGC/BGS ใช้ **loupe กำลังขยายสูง + ไฟ UV + ตรวจ ≥2 คน (PSA)** → ของปลอม/altered ได้เกรด "Altered" หรือถูก reject
- ⚠️ **ไม่การันตี 100%:** เคส Frank Thomas (ปี 2024) PSA เคยใส่สลีบการ์ดปลอมที่มีลายเซ็นจริง (ขายเกิน $1,400/ใบ) จน PSA ต้องแก้นโยบาย (Blue Label, มิ.ย. 2024)
- XRF ใช้เฉพาะการ์ดหายาก/มีข้อโต้แย้ง ไม่ใช่ทุกใบ

## ✅ Checklist ก่อนซื้อการ์ดแพง
1. [ ] เทียบหลังการ์ด (สีน้ำเงินสด ไม่อมม่วง)
2. [ ] ส่องผิว/พิมพ์/copyright มุมขวาล่าง (คมไหม)
3. [ ] เอียงดู foil (ฝังในเนื้อ ไม่ใช่สติกเกอร์)
4. [ ] เช็ค authenticity stamp (โปร่งใสไหม)
5. [ ] เทียบกับการ์ดแท้ใบเดียวกัน (รูปจากเว็บทางการ)
6. [ ] **ใบแพงมาก → ขอแบบ graded หรือซื้อจากร้านน่าเชื่อถือ**
7. [ ] sealed → เช็ค shrink-wrap + crimp

## คำถามที่ยังเปิดอยู่
1. **Weighing packs** (ชั่งซองหา hit) ใช้ได้จริงแค่ไหนกับ OP TCG + เกณฑ์น้ำหนัก — ไม่มี claim ยืนยัน
2. มีแอป/ฐานข้อมูล serial ทางการของ Bandai ให้เทียบไหม
3. วิธีตรวจ JP vs EN ต่างกันแค่ไหน (หลักฐาน primary ยึดเคส EN)
