# การเก็บรักษาการ์ด OP TCG (สภาพอากาศไทย)

> [!info] งานวิจัยรอบ 17 (2026-06-16) | หลักฐาน primary: PSA, Library of Congress, NEDCC + ข้อมูลไทย (TCG Thailand)
> 🇹🇭 **ไทยร้อนชื้น (RH 70–80%+) = ศัตรูของการ์ด** — ทำการ์ดงอ/ขึ้นรา ต้องคุมความชื้นจริงจัง

← กลับไป [[One Piece TCG - ทำกำไร (ภาพรวม)]] | เกี่ยวข้อง: [[กลยุทธ์ ส่งเกรด PSA - OP TCG]] · [[การ์ดปลอม และ วิธีดูของแท้ OP TCG]] · [[กลยุทธ์ ซื้อ Carton-Sealed - OP TCG]]

## 1️⃣ อุปกรณ์ป้องกัน (ใส่เป็นชั้น) ✅

| ชั้น | อุปกรณ์ | ใช้ทำอะไร |
|---|---|---|
| ใน | **inner sleeve** (penny / perfect-fit) | กันรอย ชั้นแรก |
| นอก | **outer/deck sleeve** | "double-sleeve" สำหรับการ์ดแพง |
| แข็ง | **toploader** (เก็บ/โชว์) หรือ **magnetic one-touch** (การ์ดแพง) | กันงอ/กระแทก |
| ส่งเกรด | **Card Saver (semi-rigid)** | สำหรับส่ง PSA โดยเฉพาะ |
| เก็บเยอะ | binder + 9-pocket (เลือกแบบ **side-loading** กันร่วง) | เก็บจำนวนมาก |

> [!tip] 🎯 double-sleeve การ์ดแพง: ใส่ perfect-fit (หันปากซองสลับทิศ) → ใส่ deck sleeve → ใส่ toploader/one-touch
> ⚠️ "penny ต้องเป็นชั้นในเสมอ" **ถูก refute** — perfect-fit มักดีกว่า

> [!warning] 🏷️ ส่งเกรด PSA = ใช้ Card Saver (semi-rigid) ไม่ใช่ toploader แข็ง! (✅ ยืนยันจาก PSA เอง)
> - PSA เตือน: ส่งใน toploader/acrylic/screw-down → **ดีเลย์ + ไม่คืนเคส + (2026) มีค่าธรรมเนียม $2**
> - เหตุผล: grader งัด semi-rigid เปิดได้ ส่วน toploader ต้องดันการ์ดออกจากล่าง = กดมุม/ขอบ
> - (PSA ยัง "รับ" toploader แต่ไม่แนะนำ — เป็น preference ไม่ใช่ห้าม)

## 2️⃣ ศัตรูของการ์ด + เป้าหมายสภาพแวดล้อม (✅ ยืนยัน primary)

| ศัตรู | ผลเสีย | ป้องกัน |
|---|---|---|
| **ความชื้น >60% RH** 🚨 | กระดาษพอง → **งอ/โก่ง (warp)** + **ขึ้นรา** (เสียถาวร) | คุม RH (ดูล่าง) |
| **แสง/UV** | สีซีด (fade) | เก็บในที่มืด/เลี่ยงแดด |
| **ความร้อน** | พลาสติก/การ์ดเสียรูป, foil เสื่อม | ห้ามทิ้งในรถ/ห้องร้อน |
| ฝุ่น/น้ำมันมือ | รอย/คราบ | ล้างมือ/จับขอบ/sleeve |

> [!check] 🎯 เป้าหมายที่ควรเก็บ
> - **ความชื้น (RH): ~45–55%** (รับได้ 40–55%, อย่าต่ำกว่า ~30% จะเปราะ) — **เกิน 60% = อันตราย (งอ+รา)**
> - **อุณหภูมิ: ~20–24°C** (68–75°F)
> - 🔑 **"ความนิ่ง (stability) สำคัญกว่าตัวเลขเป๊ะ"** — RH/อุณหภูมิแกว่งไปมาทำลายมากกว่าค่าคงที่ (กระดาษ hygroscopic ขยาย-หดทำให้ cockling/warp)
> - หลักวิทยาศาสตร์: ความร้อนเพิ่ม 10°C → ปฏิกิริยาเสื่อมเร็วขึ้น ~2 เท่า (Q10 rule, NEDCC)

> [!note] แก้ความเข้าใจผิด: **สีซีด (fade) มาจาก UV เป็นหลัก ไม่ใช่ความชื้น** | ความชื้นทำให้ **งอ + ขึ้นรา** เป็นหลัก

## 3️⃣ 🇹🇭 คุมความชื้นในไทย (✅ ยืนยัน — actionable สุด)

> [!danger] ไทย RH ปกติ 70–80%+ → **ต้องลดความชื้นเชิงรุก** (passive ไม่พอ)
> 1. **เก็บในห้องแอร์/climate-controlled** (อย่าเก็บห้องร้อน/โกดัง/ใต้หลังคา)
> 2. **เครื่องลดความชื้น (dehumidifier)** เป้า ~45–50% RH
> 3. **กล่อง/ตู้กันชื้นปิดสนิท + silica gel** (เหมือนตู้เก็บกล้อง dry cabinet)
> 4. **ไฮโกรมิเตอร์ดิจิทัล** วัด RH ตลอด (สำคัญ!)

> [!caution] ⚠️ silica gel ดูดอย่างเดียว ไม่คาย → ถ้าใส่เยอะในกล่องปิด อาจ **แห้งเกิน (<30%) จนการ์ดเปราะ**
> ทางแก้: วัดด้วยไฮโกรมิเตอร์ หรือใช้ **two-way humidity pack (เช่น Boveda ~62%)** สำหรับเก็บยาว/แผ่นfoil

## 4️⃣ เก็บ Sealed Product (box/carton) (⚠️ ยืนยันปานกลาง)
- เป้าหมายเดียวกัน: **RH ~40–50%, 18–24°C** | ถ้า RH เกิน 60% → เปิด dehumidifier
- เลี่ยง **แสง/ความร้อน** (กล่องยุบ/พลาสติกเสีย), ใช้ silica gel + ไฮโกรมิเตอร์
- > [!caution] "UV case กันกล่องเหลือง" **ถูก refute (0-3)** — กล่องเหลืองมาจากพลาสติก oxidize ตามอายุ ไม่ใช่ UV เป็นหลัก → UV case ไม่ใช่วิธีกันเหลืองที่เชื่อถือได้

## 5️⃣ เตรียมส่งเกรด — รักษา mint (✅ ยืนยัน PSA)

> [!danger] ❌ ห้าม "ทำความสะอาด/แต่ง" การ์ดก่อนส่งเกรดเด็ดขาด
> - ใส่สารใด ๆ (น้ำยาเช็ด/แว็กซ์) = PSA จัดเป็น **altered (N5)** → **ไม่ให้เกรดตัวเลข** ได้แค่ "Authentic Altered"
> - รวมถึง: trim ขอบ, ลงสีใหม่, รีดรอยยับ, ขัดรอย, เพิ่มความเงา → ถูกปฏิเสธหมด
> - → เก็บให้ **centering/edge/corner/surface ยังดี** ตั้งแต่แรก, จับขอบ/ใส่ sleeve ทันที
- ขนส่งไปเกรด: ใส่ Card Saver + team bag + แพ็คกันกระแทกแน่น (ดู [[ตัวแทนส่งเกรดในไทย และ ค่าส่งไป-กลับ - OP TCG]])

## ✅ Setup ขั้นต่ำสำหรับมือใหม่ไทย
1. การ์ดเล่น → deck sleeve | การ์ดเก็บ → penny/perfect-fit + toploader
2. **การ์ดแพง → double-sleeve + magnetic one-touch**
3. เก็บทุกอย่างใน **กล่องปิด + silica gel + ไฮโกรมิเตอร์** ในห้องแอร์
4. คุม **RH 45–55%, ~24°C, อย่าให้แกว่ง, เลี่ยงแดด**
5. **อย่าเช็ดการ์ดด้วยน้ำยา** ถ้าจะส่งเกรด

## คำถามที่ยังเปิดอยู่
1. ยี่ห้อ/ร้านขายอุปกรณ์ (Boveda, dry cabinet, sleeve) ในไทย + ราคา
2. ตัวเลข RH เป้าหมายเป๊ะ ๆ ยัง debate (40–50 vs 45–55%)
3. แหล่งส่วนใหญ่เป็น blog (ยกเว้น PSA/LoC/NEDCC) — TCG stock เคลือบต่างจากกระดาษ archival เล็กน้อย
