| ช่องทาง | ราคา/box (บาท) | ของแท้? | ซื้อง่าย? | ความเสี่ยง/ข้อจำกัด |
|---|---|---|---|---|
| 🇯🇵 **หิ้ว JP** (secondary ≤¥18,000 + tax-free) | **2,935-4,223** | ✅ | ❌ ต้องไป JP เอง | สิทธิ์ผู้โดยสาร ≤4 กล่อง |
| 🇸🇬 **หิ้ว SG** (หลัง GST refund) | **~3,350** | ✅ | ❌ ต้องไป SG + stock หมดเร็ว | สิทธิ์ผู้โดยสาร ≤5 กล่อง |
| 🇯🇵 **Ship JP MSRP case 12 box** | **~2,495** | ✅ | ❌❌ ได้ MSRP ยากมาก | ต้องมีสาย JP/wholesale |
| 🇹🇭 **SASOM** (P2P ไทย) | **4,300** | ✅ marketplace | ✅✅ ง่ายสุด | ราคา P2P ไม่ใช่ MSRP |
| 🇭🇰 **หิ้ว HK** (ไม่มีภาษี) | 4,275 | ✅ | ❌ ต้องไป HK | แทบเท่า SASOM |

| 🇹🇭 **ร้านรีเทลไทย** (Plamo ฯลฯ) | 7,500 | ✅ | ✅✅ | +75% เหนือ SASOM |

> [!tip] กฎสรุปจากตาราง
> - **ถูกสุดจริง** = หิ้ว JP/SG เอง (~3,000-3,500) แต่ติดเพดานสิทธิ์ผู้โดยสาร (4-5 กล่อง)
> - **ง่าย+ถูกสุดในไทย** (ไม่ต้องเดินทาง) = **SASOM 4,300**
> - **ทุกช่องทาง ship/นำเข้า/หิ้วจ้าง ขายต่อ SASOM = เจ๊ากับขาดทุน** (margin ปิดหมด)

## 2. เลือกตามสถานการณ์ (อ่านแถวที่ตรงกับคุณ)

| สถานการณ์ของคุณ | ซื้อจากไหน | เหตุผล |
|---|---|---|
| **เล่นเอง/เปิดสนุก 1-2 กล่อง + ไม่ได้ไปเที่ยว** | 🇹🇭 **SASOM** | ถูกสุดในไทย ซื้อง่าย ของแท้ ไม่ต้องยุ่งภาษี |
| **เล่นเอง + กำลังจะไปเที่ยว JP/SG พอดี** | 🇯🇵🇸🇬 **หิ้วเอง ≤4-5 กล่อง** | ถูกกว่า SASOM 20-32% + อยู่ในสิทธิ์ผู้โดยสาร |
| **เก็บลงทุนระยะยาว (blue-chip)** | 🇹🇭 **SASOM / ร้านไทย** | ซื้อ sealed OP-01/02/03 + MR ในไทย — ไม่ต้องนำเข้า (ขาดทุน) ดู [[ชุดไหนน่าเก็บตอนนี้ (กลางปี 2026)]] |
| **ขายต่อปริมาณน้อย (เก็งกำไร)** | ⚠️ **ซื้อ SASOM ตอนราคาดี** | หิ้ว/ship/นำเข้า ขายต่อ SASOM = เจ๊า; เก็งกำไรต้องจับจังหวะราคาในไทยแทน |
| **ทำธุรกิจ ขายปลีกจริงจัง (ปริมาณมาก)** | 🌏 **Maxsoft / Kidz & Kitz wholesale** | ทางเดียวที่ margin เป็นบวก — แต่ต้องเปิดนิติบุคคล + ขาย **retail** 6,000-7,500 ไม่ใช่ SASOM ดู [[นำเข้า OP TCG มาขายในไทย — โมเดลธุรกิจ (มิ.ย. 2026)]] |
| **อยากได้ราคา MSRP จริงๆ** | 🇺🇸 **Premium Bandai lottery** หรือ 🇯🇵 ลอตเตอรีร้าน JP | ได้ MSRP แต่ทีละ box + ต้อง forward เข้าไทย (ไม่คุ้มปริมาณ) |
| **อยากได้ 1 case (12 กล่อง) มาเปิด** | 🇹🇭 **พรีร้าน authorized ไทย** (Kidz&Kitz network / Plamo) | ของแท้ ส่งในไทย ถูกกฎหมาย ~50,000-55,000/case (retail) ดู [[วิธีพรี OP-17 ในไทย]] |

## 3. Decision Flow (ไล่ตามคำถาม)

```
เริ่ม: คุณจะเอาไปทำอะไร?
│
├─ เล่นเอง / เปิดสนุก (น้อยกล่อง)
│   ├─ กำลังจะไป JP หรือ SG พอดี?
│   │     ใช่ → 🇯🇵🇸🇬 หิ้วเอง ≤4-5 กล่อง (ถูกสุด ~3,000-3,500)
│   │     ไม่ → 🇹🇭 SASOM (4,300 ง่าย+ถูกสุดในไทย)
│   └─
│
├─ เก็บลงทุน
│     → 🇹🇭 ซื้อในไทย (SASOM/ร้าน) เน้น blue-chip ชุดต้น + MR
│        (นำเข้าเองขาดทุน — ดู [[บทวิเคราะห์ฟองสบู่ OP TCG (กลางปี 2026)]])
│
├─ ขายต่อ ปริมาณน้อย
│     → ⚠️ ไม่มีช่องทางถูกกว่า SASOM; เก็งกำไรด้วยจังหวะราคาในไทยแทน
│
└─ ทำธุรกิจ ปริมาณมาก
      ├─ เปิดนิติบุคคล/ร้านได้ไหม?
      │     ได้ → 🌏 Maxsoft/Kidz&Kitz wholesale → ขาย retail (margin +25-56%)
      │     ไม่ได้ → ❌ ไม่มีช่องทางถูกกฎหมายที่กำไร (อย่า grey import — เสี่ยงยึด)
```

## 4. กฎทอง (ข้อสรุปจากงานวิจัยทั้งหมด)

> [!important] 3 ข้อสรุปหลัก
> 1. **ไม่เดินทาง → SASOM คือคำตอบ** (ถูกสุด+ง่ายสุดในไทย ที่ 4,300/กล่อง OP-16)
> 2. **เดินทางพอดี → หิ้วเอง JP/SG ถูกกว่า 20-32%** แต่จำกัด 4-5 กล่อง (สิทธิ์ผู้โดยสาร 20,000 บาท)
> 3. **อยากกำไรจากปริมาณ → ต้องเป็นธุรกิจ (Maxsoft/Kidz&Kitz) + ขาย retail** — ไม่มีทางลัดสำหรับบุคคลธรรมดา

> [!warning] ความจริงที่ต้องยอมรับ
> หลัง **OP-17 simultaneous release** + **de minimis พัสดุยกเลิก (ม.ค. 2026)** + **ศุลกากรจับตา TCG** (เคสสะเดา) → **arbitrage ข้ามประเทศปิดเกือบหมดทุกช่องทาง** กำไรหลักจึงอยู่ที่ **เล่นในตลาดไทย** (จับจังหวะราคา/เก็บ blue-chip/ส่งเกรด) มากกว่าการเทรดข้ามประเทศ
