## 🃏 1. ความหายากของการ์ด (Rarity)

| ศัพท์ | ย่อจาก | แปลง่ายๆ |
|---|---|---|
| **C / UC / R** | Common / Uncommon / Rare | การ์ดธรรมดา → หายากน้อย (ราคาถูก) |
| **SR** | Super Rare | หายากระดับกลาง |
| **SP** | Special / Special Card | การ์ดพิเศษ (ปั๊มลายพิเศษ) — ปี 2026 ราคา**ร่วง** −8% |
| **SEC** | Secret Rare | หายากระดับสูง มักเป็น art พิเศษ |
| **L** | Leader | การ์ดหัวหน้า (ใบที่ใช้นำเด็คตอนเล่น) |
| **Leader Alt-art** | Alternate Art | การ์ด Leader ภาพวาดพิเศษ — **ของแพง ขึ้น +30%** |
| **MR / Manga Rare** | Manga Rare | ⭐ การ์ดลายมังงะขาวดำ **หายากสุด+แพงสุด** (เช่น Luffy/Zoro/Shanks) pull rate 1:500-1,500 ซอง |
| **TR** | Treasure Rare | rarity ใหม่ ลายพิเศษ — ปี 2026 ราคา**ร่วงแรง** −19% |
| **Alt-art / Parallel** | Alternate / Parallel | ใบเดียวกันแต่ภาพ/ลายต่าง (มักแพงกว่าใบปกติ) |
| **Chase card** | — | "การ์ดเป้าหมาย" ของชุดนั้น ที่ทุกคนอยากได้ (แพงสุดในชุด) |

> 💡 จำง่าย: **MR + Leader Alt-art = ของ blue-chip (แพง/ทน)** · **SR/TR/SP ชุดใหม่ = ของเก็งกำไร (ร่วงง่าย)**

## 🛡️ 2. สภาพการ์ด + การเกรด (Grading)

| ศัพท์ | แปลง่ายๆ |
|---|---|
| **Raw** | การ์ดดิบ ยังไม่ส่งเกรด (อยู่ในซอง/sleeve เฉยๆ) |
| **Graded** | การ์ดที่ส่งบริษัทประเมินสภาพแล้ว ใส่กล่องพลาสติกซีล |
| **Slab** | กล่องพลาสติกแข็งที่หุ้มการ์ด graded (แสลงเรียก "สแลบ") |
| **PSA / CGC / BGS** | 3 บริษัทเกรดดังของโลก (PSA นิยมสุด) |
| **PSA 10** | เกรดเต็ม 10 = Gem Mint (สภาพสมบูรณ์แบบ) — **ราคาพุ่งหลายเท่าของ raw** |
| **Gem Mint** | สภาพเพอร์เฟกต์ (มุมคม/กลาง/ผิวไม่มีตำหนิ) |
| **Centering** | ความสมดุลของขอบภาพ (เบี้ยว = เกรดตก) |
| **Population (Pop)** | จำนวนใบที่ได้เกรดนั้นทั้งโลก — **Pop สูง = ของไม่หายาก = upside ถูกจำกัด** |

## 📦 3. สินค้า + บรรจุภัณฑ์

| ศัพท์ | แปลง่ายๆ |
|---|---|
| **Pack / ซอง** | ซองเล็กสุด = 6 ใบ (OP มาตรฐาน) |
| **Box / Display / บ็อกซ์** | 1 กล่อง = 24 ซอง |
| **Case / Carton / คาตั้น / ลัง** | 1 ลัง = **12 box = 288 ซอง** (Premium Booster = 10 box) |
| **Sealed** | สินค้าซีลใหม่ ยังไม่แกะ (เก็บ/ลงทุนนิยมแบบนี้) |
| **Booster** | ซอง/กล่องสุ่มการ์ด (ตัวหลักที่ซื้อขาย) |
| **Starter Deck (ST)** | เด็คสำเร็จรูปพร้อมเล่น (สำหรับมือใหม่) |
| **MSRP / RRP** | ราคาขายปลีกที่ผู้ผลิตแนะนำ (= ราคา "ป้าย" ถูกสุด แต่มักซื้อจริงไม่ได้) |

## 💹 4. การเทรด / เก็งกำไร

| ศัพท์ | แปลง่ายๆ |
|---|---|
| **Flip** | ซื้อมาขายไปเร็วๆ เอากำไรส่วนต่าง (ระยะวัน-สัปดาห์) |
| **Swing** | ถือระยะกลาง (เดือน) รอจังหวะราคาขึ้นแล้วขาย |
| **Hold** | ถือยาว (ปี) รอราคาโตขึ้นเรื่อยๆ |
| **Blue-chip** | ของคุณภาพสูง ราคามั่นคง/ทนตลาดร่วง (เช่น sealed ชุดต้น, MR PSA10) |
| **Release Dip** | ⭐ ปรากฏการณ์ราคาชุดใหม่**ร่วงหลังวาง 4-8 สัปดาห์** (จังหวะซื้อถูก) |
| **EV (Expected Value)** | มูลค่าคาดหวัง — เช่น "จุ่ม EV ติดลบ" = เฉลี่ยแล้วขาดทุน |
| **FOMO** | Fear Of Missing Out = กลัวตกรถ → ไล่ซื้อตอนแพง (กับดักคนเจ๊ง) |
| **Spread** | ส่วนต่างราคาซื้อ-ขาย / ราคาตั้งขาย vs ราคาขายจริง |
| **Position Sizing** | การแบ่งเงินลงแต่ละดีล ไม่ทุ่มหมดที่เดียว |
| **Stop-Loss** | จุดตัดขาดทุน (ขายทิ้งเมื่อราคาตกถึงระดับที่ตั้งไว้) |
| **Sell-through** | อัตราการขายออก (ขายหมดเร็ว = demand ดี) |

## 📈 5. ตลาด / วงจรราคา

| ศัพท์ | แปลง่ายๆ |
|---|---|
| **Secondary market** | ตลาดรอง = ซื้อขายมือสอง/ต่อจากร้าน (ราคาจริงในตลาด) |
| **P2P** | Peer-to-Peer = ซื้อขายระหว่างคนต่อคน (เช่น SASOM, Carousell) |
| **Meta** | เด็ค/การ์ดที่ "นิยมในการแข่ง" ตอนนั้น → meta เปลี่ยน ราคาการ์ดเปลี่ยน |
| **Hype** | กระแสความนิยมพุ่ง (ดันราคาขึ้นชั่วคราว) |
| **Hot money** | เงินเก็งกำไรที่ไหลเข้าเร็ว → ไหลออกเร็ว (ทำราคาผันผวน) |
| **Bubble / ฟองสบู่** | ราคาพองเกินมูลค่าจริง เสี่ยง "แตก" (ร่วงแรง) |
| **Bull / Bear / Base** | ตลาดขาขึ้น / ขาลง / ทรงตัว (3 scenario ในบทวิเคราะห์) |
| **Distribution Phase** | ช่วง "กระจายของ" — เงินฉลาดเริ่มขายออก ก่อนตลาดตัดสินทิศ |
| **Leading indicator** | ตัวชี้นำล่วงหน้า (เช่น ราคา JP นำราคาโลก ~2 สัปดาห์) |
| **Reprint** | ผู้ผลิตพิมพ์การ์ดเดิมซ้ำ → **supply เพิ่ม → ราคาตก** |
| **Reserved List** | สัญญา "จะไม่ reprint" (MTG มี / **OP TCG ไม่มี** = เสี่ยง reprint เสมอ) |

## 🛂 6. นำเข้า / ส่งออก / ภาษี

| ศัพท์ | แปลง่ายๆ |
|---|---|
| **Landed Cost** | ต้นทุน "ถึงมือ" จริง = ราคาของ + ค่าส่ง + ภาษี + ค่าธรรมเนียมทั้งหมด |
| **CIF** | Cost + Insurance + Freight = ราคาของ+ประกัน+ค่าส่ง (ฐานคิดภาษีนำเข้า) |
| **De minimis** | วงเงินของถูก ที่ได้**ยกเว้นภาษี** — ⚠️ ไทยยกเลิกสำหรับพัสดุแล้ว (ม.ค. 2026) |
| **Traveler Allowance** | สิทธิ์ผู้โดยสารถือของเข้าประเทศโดยไม่เสียภาษี (ไทย = 20,000 บาท/คน) |
| **อากร (Duty)** | ภาษีนำเข้า (% ของราคา CIF) |
| **VAT** | ภาษีมูลค่าเพิ่ม (ไทย 7%) |
| **HS Code** | รหัสพิกัดสินค้าศุลกากร (การ์ดเกม = 9504.40) |
| **หิ้ว** | ซื้อต่างประเทศแล้วถือกลับเอง/จ้างคนถือกลับ (ไม่ใช่ส่งพัสดุ) |
| **Proxy / Forwarder** | บริการซื้อแทน/รับพัสดุต่อ จากต่างประเทศ (เช่น ZenMarket, Buyee) |
| **Arbitrage** | ทำกำไรจากส่วนต่างราคาระหว่างตลาด (ซื้อถูกที่หนึ่ง ขายแพงอีกที่) |
| **IOR** | Importer of Record = ผู้รับผิดชอบนำเข้าตามกฎหมาย (ต้องเป็นนิติบุคคล) |
| **Grey import** | นำเข้าแบบเลี่ยง/ไม่ผ่านพิธีการเต็ม (ผิดกฎหมาย เสี่ยงยึด) |

## 🏪 7. แพลตฟอร์ม / แหล่งซื้อขาย

| ชื่อ | คืออะไร |
|---|---|
| **SASOM** | marketplace ไทย (P2P) การันตีของแท้ — ราคาถูกสุดในไทย |
| **TCGplayer** | marketplace การ์ด EN ใหญ่สุดของโลก (US) = ราคาอ้างอิงโลก |
| **Mercari JP / Yahoo Auctions** | ตลาดมือสองญี่ปุ่น (ราคา JP ล่วงหน้า) |
| **Carousell** | marketplace P2P สิงคโปร์/SEA |
| **eBay** | marketplace global (ขายออกนอกจากไทยได้) |
| **Cardmarket** | marketplace การ์ดใหญ่สุดของยุโรป |
| **Distributor** | ตัวแทนจำหน่ายทางการ (SEA = Maxsoft, ไทย = Kidz & Kitz) |
| **Authorized retailer** | ร้านค้าที่ได้รับสิทธิ์ขายทางการจาก distributor |
